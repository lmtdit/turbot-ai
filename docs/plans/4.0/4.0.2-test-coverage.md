## P0-3：修复 7 个失败测试

> **状态**：✅ 已完成
> **实际完成**：CMakeLists.txt 已添加双路径复制，`tests/prompts/` 目录路径与 `build/prompts/` 共同运行。全部 7 个失败测试已恢复通过。
> **依赖**：无
> **影响版本**：v2.x

### 问题描述

`system_prompt_test.cpp`（12 个断言）和 `prompt_builder_test.cpp`（2 个断言）失败。

**根因**：`system_prompt.cpp` 通过 `current_path() / "prompts"` 加载文件。测试运行工作目录为 `build/debug/tests/`，但 `copy_prompts` CMake target 将文件复制到 `build/debug/prompts/`（上级目录），导致路径不匹配，fallback 到内嵌字符串，缺少测试断言需要的 section。

### 修复方向

修改 `tests/CMakeLists.txt`，在 `copy_prompts` 自定义命令中同时将 prompts 复制到 `${CMAKE_BINARY_DIR}/tests/prompts/`：

```cmake
add_custom_command(
  TARGET copy_prompts POST_BUILD
  COMMAND ${CMAKE_COMMAND} -E copy_directory
    ${CMAKE_SOURCE_DIR}/prompts
    ${CMAKE_BINARY_DIR}/prompts
  COMMAND ${CMAKE_COMMAND} -E copy_directory   # 新增
    ${CMAKE_SOURCE_DIR}/prompts                # 新增
    ${CMAKE_BINARY_DIR}/tests/prompts          # 新增
)
```

### Refactor-2: 扩展 `crypto_utils` 支持文件哈希

**文件**: `libs/utils/include/turbot/utils/crypto_utils.hpp`（新增声明）

```cpp
/// Compute SHA-256 hash of file contents
/// @param path Path to the file
/// @return Hex-encoded SHA-256 hash, or empty string if file cannot be read
[[nodiscard]] TURBOT_UTILS_API std::string sha256_file(const std::filesystem::path& path);
```

**文件**: `libs/utils/src/crypto_utils.cpp`（新增实现）

```cpp
#include <turbot/utils/file_utils.hpp>

std::string sha256_file(const std::filesystem::path& path) {
    auto content = read_file(path.string());
    if (!content.has_value()) return "";
    return sha256(*content);
}
```

**文件**: `libs/core/src/snapshot/snapshot.cpp`（使用新函数）

```cpp

}

// 修改后（使用新的专用函数）
std::string SnapshotManager::compute_file_hash(const std::filesystem::path& path) {
```

```cpp
std::string SnapshotManager::read_file_content(const std::filesystem::path& path) {
    std::ifstream file(path, std::ios::binary);
    if (!file) return "";
    std::stringstream buffer;
    buffer << file.rdbuf();
    return buffer.str();
}

}
```

## 测试用例

```cpp
// tests/unit/crypto_utils_test.cpp 中新增

TEST_CASE("sha256_file: hash known file content", "[utils][crypto]") {
    // 创建临时文件
    auto tmp = std::filesystem::temp_directory_path() / "sha256_test.txt";
    std::ofstream(tmp) << "hello world";

    std::string hash = turbot::utils::crypto::sha256_file(tmp);

    // sha256("hello world") = b94f6f125c79...
    CHECK_FALSE(hash.empty());
    CHECK(hash.length() == 64);  // SHA-256 hex 字符串长度

    std::filesystem::remove(tmp);
}

TEST_CASE("sha256_file: non-existent file returns empty", "[utils][crypto]") {
    std::string hash = turbot::utils::crypto::sha256_file("/non/existent/file.txt");
    CHECK(hash.empty());
}

TEST_CASE("sha256_file: consistent with sha256(content)", "[utils][crypto]") {
    auto tmp = std::filesystem::temp_directory_path() / "sha256_consistent.txt";
    std::string content = "test content for consistency check";
    std::ofstream(tmp) << content;

    std::string file_hash = turbot::utils::crypto::sha256_file(tmp);
    std::string content_hash = turbot::utils::crypto::sha256(content);

    CHECK(file_hash == content_hash);

    std::filesystem::remove(tmp);
}
```

## 变更详情

### Fix-T1: E2E-07 重试测试断言强化

**文件**: `tests/integration/e2e_test.cpp`

**问题**：

```cpp
TEST_CASE_METHOD(E2ETest, "E2E-07: Error Retry", "[e2e][e2e-07]") {
    setup_error_sequence({ MockError::RateLimitExceeded, MockError::NetworkError, MockError::None });
    setup_simple_qa("Success after retries!");
    loop->run("Test retry logic");

    // 断言过弱：>= 1 无法证明重试发生
    CHECK(provider->call_count() >= 1);
}
```

**修复**：精确验证重试次数和最终结果。

```cpp
TEST_CASE_METHOD(E2ETest, "E2E-07: Error Retry", "[e2e][e2e-07]") {
    // 配置：2 次错误后成功
    setup_error_sequence({ MockError::RateLimitExceeded, MockError::NetworkError, MockError::None });
    setup_simple_qa("Success after retries!");

    auto result = loop->run("Test retry logic");

    // 验证：明确预期重试至少 3 次（2 次失败 + 1 次成功）
    CHECK(result == session::LoopResult::Stop);
    CHECK(provider->call_count() >= 3);

    // 验证最终响应内容正确传递
    const auto& msgs = loop->messages();
    REQUIRE_FALSE(msgs.empty());
    bool found_success = false;
    for (const auto& msg : msgs) {
        if (msg.role() == Role::Assistant) {
            found_success = true;
        }
    }
    CHECK(found_success);
}
```

### Fix-T2: E2E-08 Doom Loop 检测断言强化

**文件**: `tests/integration/e2e_test.cpp`

**问题**：

```cpp
TEST_CASE_METHOD(E2ETest, "E2E-08: Doom Loop Detection", "[e2e][e2e-08]") {
    // ...配置 5 次相同工具调用...
    loop->run("Keep doing the same thing");

    // 断言含义模糊，注释说"应停止或继续"——两者都验证了等于没验证
    CHECK(provider->call_count() <= config.doom_loop_threshold + 1);
}
```

**修复**：验证循环被 doom loop 机制终止，结果为 `LoopResult::Error`（`LoopResult` 无 `DoomLoop` 枚举值）。

```cpp
TEST_CASE_METHOD(E2ETest, "E2E-08: Doom Loop Detection", "[e2e][e2e-08]") {
    session::SessionLoopConfig config;
    config.doom_loop_threshold = 3;
    loop->set_config(config);

    // 配置 5 次完全相同的工具调用（name + input 都相同）
    nlohmann::json same_input = {{"param", "same_value"}};
    for (int i = 0; i < 5; i++) {
        setup_tool_call("same_tool", "tool-" + std::to_string(i), same_input);
    }

    auto result = loop->run("Keep doing the same thing");

    // 验证：doom loop 机制必须触发（返回 Error，LoopResult 无 DoomLoop 枚举值）
    CHECK(result == session::LoopResult::Error);

    // 验证：LLM 调用次数不超过阈值 + 1（不允许无限调用）
    CHECK(provider->call_count() <= config.doom_loop_threshold + 1);
}
```

```cpp
TEST_CASE_METHOD(E2ETest, "ERR-01: API error auto retry", "[integration][error]") {

    setup_error_sequence({ MockError::RateLimitExceeded, MockError::RateLimitExceeded, MockError::None });
```

```cpp
            has_assistant_msg = true;
            break;
        }

    CHECK(has_assistant_msg);
```

### Fix-T4: PERSIST-07 真并发测试

**文件**: `tests/integration/persistence_test.cpp`

**问题**：测试名为"Concurrent message creation"，但实为单线程 for 循环，不验证任何并发安全性。

```cpp
TEST_CASE_METHOD(PersistenceTestFixture, "PERSIST-07: Concurrent message creation", ...) {
    // 实为串行 for 循环，名不副实
    for (int i = 0; i < 10; i++) {
        Message msg(...);
        dao.create_message(msg.info());
    }
    auto messages = dao.list_messages_by_session(session_result->id());
    CHECK(messages.size() == 10);
}
```

**修复方案 A（推荐）**：改名为精确描述实际行为，保留串行测试但再新增一个真并发用例。

```cpp
// 保留串行测试，但精确命名
TEST_CASE_METHOD(PersistenceTestFixture,
    "PERSIST-07: Sequential message creation integrity",
    "[integration][persistence]")
{
    // （原有串行测试代码不变）
    auto session_result = session::Session::create(params);
    REQUIRE(session_result.has_value());

    MessageDao dao(db);
    std::vector<std::string> message_ids;
    for (int i = 0; i < 10; i++) {
        Message msg(session_result->id(), Role::User, "build", "", "");
        msg.add_text("Message " + std::to_string(i));
        dao.create_message(msg.info());
        message_ids.push_back(msg.id());
    }

    auto messages = dao.list_messages_by_session(session_result->id());
    CHECK(messages.size() == 10);

    // 新增：验证每条消息 ID 唯一（UUID 不重复）
    std::unordered_set<std::string> id_set(message_ids.begin(), message_ids.end());
    CHECK(id_set.size() == 10);
}

// 新增：真并发测试
TEST_CASE_METHOD(PersistenceTestFixture,
    "PERSIST-07b: Concurrent message creation (multi-thread)",
    "[integration][persistence][concurrent]")
{
    auto session_result = session::Session::create(params_concurrent);
    REQUIRE(session_result.has_value());

    const int thread_count = 4;
    const int msgs_per_thread = 5;
    std::vector<std::thread> threads;
    std::atomic<int> success_count{0};

    for (int t = 0; t < thread_count; t++) {
        threads.emplace_back([&, t]() {
            MessageDao thread_dao(db);  // 每线程独立 dao（SQLite WAL 模式）
            for (int i = 0; i < msgs_per_thread; i++) {
                Message msg(session_result->id(), Role::User, "build", "", "");
                msg.add_text("Thread " + std::to_string(t) + " msg " + std::to_string(i));
                if (thread_dao.create_message(msg.info())) {
                    success_count.fetch_add(1, std::memory_order_relaxed);
                }
            }
        });
    }

    for (auto& th : threads) th.join();

    // 验证：所有消息均成功写入
    CHECK(success_count == thread_count * msgs_per_thread);
    auto messages = MessageDao(db).list_messages_by_session(session_result->id());
    CHECK(messages.size() == static_cast<size_t>(thread_count * msgs_per_thread));
}
```

### Fix-T5: MockProvider timeout_behavior 实现

**文件**: `tests/mock/mock_provider.hpp`

**问题**：`timeout_after_` 和 `timeout_then_succeed_` 字段设置后在 `chat()` / `chat_stream()` 中均未使用。

```cpp
// 字段已声明（line ~260）
int timeout_after_ = -1;
bool timeout_then_succeed_ = false;

// 但 chat() 和 chat_stream() 均未检查这些字段
```

**修复**：在 `chat()` 和 `chat_stream()` 开头处检查 timeout 配置：

```cpp
[[nodiscard]] core::provider::ChatResponse chat(
    const std::vector<core::provider::ChatMessage>& messages,
    const std::string& model_id,
    const core::provider::ChatOptions& options
) override {
    std::lock_guard<std::mutex> lock(mutex_);
    // ...
    call_count_++;

    // ← 新增：timeout 模拟
    if (timeout_after_ >= 0 && call_count_ > timeout_after_) {
        if (!timeout_then_succeed_) {
            throw std::runtime_error("MockProvider: simulated timeout");
        }
        // timeout_then_succeed_ = true：超过 timeout_after_ 次后恢复正常
    }

    // ...（原有逻辑不变）
}
```

`chat_stream()` 同理，在回调循环开始前检查：

```cpp
[[nodiscard]] core::provider::ChatResponse chat_stream(
    const std::vector<core::provider::ChatMessage>& messages,
    const std::string& model_id,
    const core::provider::ChatOptions& options,
    core::provider::StreamCallback callback
) override {
    // 提前取出需要的数据，避免持锁调用 callback
    std::vector<std::string> chunks;
    bool should_timeout = false;
    {
        std::lock_guard<std::mutex> lock(mutex_);
        // ... 原有数据取出逻辑
        call_count_++;
        // ← 新增：timeout 检查
        if (timeout_after_ >= 0 && call_count_ > timeout_after_ && !timeout_then_succeed_) {
            should_timeout = true;
        }
        chunks = stream_chunks_;
    }

    if (should_timeout) {
        throw std::runtime_error("MockProvider: simulated timeout");
    }

    // 在锁外调用 callback（同时修复 C-2 死锁）
    if (callback) {
        for (const auto& chunk : chunks) {
            // ...
            callback(event);
        }
    }
    // ...
}
```

**新增测试用例**（`tests/unit/mock_provider_test.cpp` 或内嵌）：

```cpp
TEST_CASE("MockProvider: timeout_behavior triggers exception", "[mock][timeout]") {
    auto provider = std::make_shared<MockProvider>("test-key");
    provider->set_timeout_behavior(2, false);  // 第 3 次调用开始 timeout

    // 前两次成功
    provider->set_next_response(make_simple_response("ok1"));
    provider->set_next_response(make_simple_response("ok2"));
    CHECK_NOTHROW(provider->chat({}, "model", {}));
    CHECK_NOTHROW(provider->chat({}, "model", {}));

    // 第三次 timeout
    CHECK_THROWS_AS(provider->chat({}, "model", {}), std::runtime_error);
}

TEST_CASE("MockProvider: timeout_then_succeed allows recovery", "[mock][timeout]") {
    auto provider = std::make_shared<MockProvider>("test-key");
    provider->set_timeout_behavior(1, true);  // 第 2 次后恢复

    provider->set_next_response(make_simple_response("ok1"));
    provider->set_next_response(make_simple_response("ok2"));  // timeout 后仍成功

    CHECK_NOTHROW(provider->chat({}, "model", {}));
    CHECK_NOTHROW(provider->chat({}, "model", {}));  // 不抛出
}
```

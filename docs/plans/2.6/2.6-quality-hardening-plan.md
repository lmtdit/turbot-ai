# Turbot-AI 质量加固计划 (v2.6)

> **创建时间**: 2026-03-10
> **目标**: 修复 v2.5 代码审核发现的 Critical/Major 问题，完成公共模块提升，达到质量门禁
> **前置条件**: v2.5 全部计划已完成

## 概述

v2.6 是 v2.5 与 v3.0 之间的**质量加固版本**，专注于：

1. **修复 Critical 问题**：线程安全、死锁风险、角色语义错误、弃用 API
2. **公共模块提升**：消除重复代码，统一至 `libs/utils`
3. **测试质量提升**：补强弱验证测试，修复误导性测试
4. **文档对齐**：更新 v2.5 遗留的文档与实现不一致问题

v2.6 完成后，代码库将满足进入 v3.0 协议系统开发所需的质量门禁要求。

## 与 v3.0 的关系

v2.6 完成后，v3.0 协议系统开发将在以下改善的基础之上进行：

1. **线程安全的 SnapshotManager** —— MCP 工具调用会频繁触发文件追踪
2. **正确的 Role::Tool 语义** —— ACP 协议需要准确区分工具结果消息
3. **统一的 utils 基础设施** —— 新模块（MCP/LSP/ACP）可直接复用
4. **可靠的集成测试框架** —— 用于验证协议系统的 E2E 行为

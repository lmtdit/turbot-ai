## 一、工具系统（P0）

### P0-1：apply_patch 工具缺失 ✅

**现状**：Turbot 无 apply_patch 工具，无法应用 diff patch 文件。

**OpenCode 实现**：

- 文件：`opencode/packages/opencode/src/tool/apply_patch.ts`
- 功能：解析 unified diff 格式，应用到目标文件
- 支持 GPT 模型的 codex 格式

**修复方向**：

1. 创建 `libs/core/src/tool/builtin/apply_patch_tool.cpp`
2. 实现 unified diff 解析器
3. 支持文件创建/修改/删除操作
4. 注册到 ToolRegistry

**验收标准**：

- [x] 编译通过
- [x] apply_patch 工具在 ToolRegistry 中注册
- [x] 可解析并应用 unified diff
- [x] 单元测试覆盖率 ≥ 85%

### P0-3：invalid 工具缺失 ✅

# 2.7.4 Snapshot 内存策略优化

> **工时**: 1 天
> **测试类型**: 单元测试
> **依赖**: 无
> **状态**: ✅ 已完成（2026-03-11）

---

## 目标

解决 `SnapshotManager::scan_files()` 全量缓存文件内容的 OOM 风险，同时保留 `PatchResult::FileChange::old_content` 的原有功能语义。

---

## 背景

### 设计澄清

v2.6 审查报告曾建议"删除 `scan_files()` 中的内容缓存"，但二次核实发现这是**有意设计**：

```cpp
// snapshot.cpp:299-300
data.file_hashes[path_str]   = compute_file_hash(path);
data.file_contents[path_str] = read_file_content(path);  // 为 old_content 准备
```

`stop_tracking()` 在检测到文件修改或删除时，需要提供修改前的内容（`old_content`），用于生成可逆的 `PatchResult`：

```cpp
// snapshot.cpp:393-402
} else if (old_it->second != current_hash) {
    auto content_it = data.file_contents.find(path_str);
    result.files.push_back({
        .old_content = (content_it != data.file_contents.end())
                       ? content_it->second : "",  // ← 依赖 file_contents
        // ...
    });
}
```

因此，**不能简单删除** `file_contents`。正确的优化策略是：

1. 添加缓存上限配置，超限时跳过内容缓存
2. 超限时 `old_content` 降级为空字符串（`""`），并记录日志

### 风险场景

| 场景                                              | 当前行为         | 问题                 |
| ------------------------------------------------- | ---------------- | -------------------- |
| 大型 monorepo（10k 文件 × 平均 50KB）             | 缓存 ~500MB 内存 | OOM                  |
| 超大单文件（99MB，略低于 `read_file` 100MB 限制） | 缓存 99MB        | 单次追踪占用过多内存 |
| 文件数量正常但含二进制文件（图片、库）            | 缓存二进制内容   | 无效缓存             |

## 变更详情

### Opt-M1: 新增 `max_cache_size_mb` 配置项

**文件**: `libs/core/include/turbot/core/snapshot/snapshot.hpp`

**修改 `SnapshotOptions`**:

```cpp
struct SnapshotOptions {
    std::filesystem::path root_directory;
    std::vector<std::string> exclude_patterns;
    std::function<bool(const std::filesystem::path&)> file_filter;

    /// Maximum total size (MB) of file content to cache in memory for diff generation.
    /// Files that would push the cache over this limit are hashed only (no old_content in PatchResult).
    /// Default: 50 MB. Set to 0 to disable content caching entirely (hash-only mode).
    size_t max_cache_size_mb = 50;

    [[nodiscard]] static std::vector<std::string> default_exclude_patterns();
};
```

### Opt-M2: 修改 `scan_files()` 实现上限控制

**文件**: `libs/core/src/snapshot/snapshot.cpp`

```cpp
void SnapshotManager::scan_files(SnapshotData& data) {
    const auto& root = data.options.root_directory;
    if (root.empty()) return;

    // Calculate cache budget in bytes
    const size_t max_cache_bytes = data.options.max_cache_size_mb * 1024ULL * 1024ULL;
    size_t cached_bytes = 0;

    std::error_code ec;
    for (const auto& entry : std::filesystem::recursive_directory_iterator(root, ec)) {
        if (ec) { ec.clear(); continue; }
        if (!entry.is_regular_file()) continue;

        const auto& path = entry.path();
        if (!should_track(path, data)) continue;

        std::string path_str = path.string();
        data.file_hashes[path_str] = compute_file_hash(path);

        // Content caching: only if budget allows
        if (max_cache_bytes > 0 && cached_bytes < max_cache_bytes) {
            namespace fs = std::filesystem;
            auto file_size = fs::file_size(path, ec);
            if (!ec && (cached_bytes + file_size) <= max_cache_bytes) {
                auto content = read_file_content(path);
                if (!content.empty()) {
                    cached_bytes += content.size();
                    data.file_contents[path_str] = std::move(content);
                }
            } else {
                TURBOT_LOG_DEBUG("scan_files: skipping content cache for {} "
                                 "(cache budget {}MB reached)", path_str,
                                 data.options.max_cache_size_mb);
            }
        }
    }

    if (cached_bytes > 0) {
        TURBOT_LOG_DEBUG("scan_files: cached {:.1f} MB of file content",
                         static_cast<double>(cached_bytes) / (1024 * 1024));
    }
}
```

### Opt-M3: 更新 `stop_tracking()` 处理内容缺失

`stop_tracking()` 中访问 `file_contents` 的两处已有 fallback（`""` when not found），**无需修改**：

```cpp
// 已有：若 file_contents 中不存在，old_content 为 ""
.old_content = (content_it != data.file_contents.end()) ? content_it->second : ""
```

补充日志，使超限情况可追踪：

```cpp
auto content_it = data.file_contents.find(path_str);
if (content_it == data.file_contents.end()) {
    TURBOT_LOG_DEBUG("stop_tracking: old_content unavailable for {} "
                     "(file not cached, may exceed size limit)", path_str);
}
result.files.push_back({
    .old_content = (content_it != data.file_contents.end()) ? content_it->second : "",
    // ...
});
```

### SNAP-MEM-02: 内容缓存模式仍正确提供 old_content

```cpp
TEST_CASE("SNAP-MEM-02: file_contents cache provides old_content in PatchResult",
          "[unit][snapshot]") {
    SnapshotOptions opts;
    auto test_dir = create_temp_dir();
    write_file(test_dir / "a.txt", "original content");
    opts.root_directory = test_dir;
    opts.max_cache_size_mb = 50;  // 默认值，内容应被缓存

    auto& mgr = SnapshotManager::instance();
    auto id = mgr.start_tracking(opts);

    // Modify file after tracking starts
    write_file(test_dir / "a.txt", "modified content");

    auto patch = mgr.stop_tracking(id);

    REQUIRE(patch.files.size() == 1);
    CHECK(patch.files[0].type == FileChangeType::Modified);
    CHECK(patch.files[0].old_content == "original content");  // 来自缓存
    CHECK(patch.files[0].new_content == "modified content");
}
```

### SNAP-MEM-03: `reset_for_testing()` 正确清理状态（TURBOT_TESTING build）

```cpp
#ifdef TURBOT_TESTING
TEST_CASE("SNAP-MEM-03: reset_for_testing clears all snapshots", "[unit][snapshot]") {
    auto& mgr = SnapshotManager::instance();
    SnapshotOptions opts;
    opts.root_directory = std::filesystem::temp_directory_path();
    opts.max_cache_size_mb = 0;

    auto id = mgr.start_tracking(opts);
    CHECK(mgr.active_tracking_count() == 1);

    mgr.reset_for_testing();
    CHECK(mgr.active_tracking_count() == 0);
}
#endif
```

```cpp
TEST_CASE_METHOD(E2ETest, "E2E-07: Error Retry", "[e2e][e2e-07]") {
    // Configure: 2 errors then success
    setup_error_sequence({
        MockError::RateLimitExceeded,
        MockError::NetworkError,
        MockError::None
    });
    setup_simple_qa("Success after retries!");

    auto result = loop->run("Test retry logic");

    // Retry must succeed: 2 errors + 1 success = 3 LLM calls minimum
    CHECK(result == session::LoopResult::Stop);
    CHECK(provider->call_count() >= 3);

    // Verify a successful assistant message was generated
    bool has_assistant = false;
    for (const auto& msg : loop->messages()) {
        if (msg.role() == Role::Assistant && !msg.get_text().empty()) {
            has_assistant = true; break;
        }
    }
    CHECK(has_assistant);
}
```

**修复方案（按 2.7.1 结论 B，重试未集成）**:

```cpp
TEST_CASE_METHOD(E2ETest, "E2E-07: Error Propagation (no internal retry)", "[e2e][e2e-07]") {
    // Configure: first call returns error
    setup_error_sequence({
        MockError::RateLimitExceeded,
        MockError::None
    });
    setup_simple_qa("This would succeed if retried.");

    std::string error_code;
    loop->set_on_error([&](const std::string& /*msg*/, const std::string& code) {
        error_code = code;

    CHECK(result == session::LoopResult::Error);
    CHECK(provider->call_count() == 1);         // Exactly 1 call (no retry)
    CHECK(error_code == "llm_error");            // Error callback fired with correct code
}
```

### Fix-T2: E2E-08 Doom Loop 断言修正

**文件**: `tests/integration/e2e_test.cpp:182-202`

**问题**: 断言允许 `Stop || Error`，且注释含糊"either by doom loop Error or natural Stop"。

**当前代码**:

```cpp
// 断言含义模糊
CHECK((result == session::LoopResult::Error || result == session::LoopResult::Stop));
```

**修复**:

```cpp
TEST_CASE_METHOD(E2ETest, "E2E-08: Doom Loop Detection", "[e2e][e2e-08]") {
    session::SessionLoopConfig config;
    config.doom_loop_threshold = 3;
    loop->set_config(config);

    nlohmann::json same_input = {{"param", "same_value"}};
    for (int i = 0; i < 5; i++) {
        setup_tool_call("same_tool", "tool-" + std::to_string(i), same_input);
    }

    std::string error_code;
    loop->set_on_error([&](const std::string& /*msg*/, const std::string& code) {
        error_code = code;
    });

    auto result = loop->run("Keep doing the same thing");

    // Doom loop MUST terminate with Error (not Stop)
    // Note: LoopResult has no DoomLoop variant; doom loop returns Error
    CHECK(result == session::LoopResult::Error);
    CHECK(error_code == "doom_loop");

    // LLM called at most threshold + 1 times
    CHECK(provider->call_count() <= config.doom_loop_threshold + 1);
}
```

> **说明**：E2E-08b 已正确验证了上述语义，E2E-08 修正后与 E2E-08b 形成互补（E2E-08 用"无注册工具"的简化场景，E2E-08b 用"真实工具执行"的完整场景）。

### Fix-T4: PERSIST-07b 并发测试返回值修复

**文件**: `tests/integration/persistence_test.cpp:382-400`

**问题**: `create_message()` 返回值被丢弃，`success_count` 无条件递增，写入失败时测试仍通过。

**当前代码**:

```cpp
thread_dao.create_message(msg.info());       // 返回值被丢弃
success_count.fetch_add(1, std::memory_order_relaxed);
```

**修复**:

```cpp
bool ok = thread_dao.create_message(msg.info());
if (ok) {
    success_count.fetch_add(1, std::memory_order_relaxed);
} else {
    TURBOT_LOG_ERROR("PERSIST-07b: create_message failed in thread {}, msg {}", t, i);
}
```

> **说明**：不使用 `REQUIRE(ok)` 的原因是 `REQUIRE` 在多线程中可能导致 Catch2 断言竞争（Catch2 的全局状态非线程安全）。改为条件递增 + 日志，最终在主线程通过 `CHECK(success_count == ...)` 验证。

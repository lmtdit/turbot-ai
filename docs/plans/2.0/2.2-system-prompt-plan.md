### 核心接口

```cpp
namespace turbot::core::llm {

/// Provider 类型枚举
enum class ProviderType {
    OpenAI, Anthropic, Gemini, Codex, Trinity, Other
};

/// 系统提示词构建参数
struct SystemPromptParams {
    std::string session_id;
    agent::AgentInfo agent;
    std::string model_id;
    std::string provider_id;
    std::string working_directory;
    bool is_git_repo = false;
    std::string platform;
    std::string current_date;
    std::vector<std::string> custom_prompts;
    std::vector<std::string> user_system_prompts;
};

/// 系统提示词构建器
class SystemPrompt {
public:
    static std::string build(const SystemPromptParams& params);
    static std::string instructions();
    static std::string provider_prompt(std::string_view provider_id, std::string_view model_id);
    static std::string environment(const SystemPromptParams& params);
    static std::string agent_prompt(const agent::AgentInfo& agent);
    static std::string join_prompts(const std::vector<std::string>& parts);

    // Provider 特定模板
    static std::string prompt_anthropic();
    static std::string prompt_openai();
    static std::string prompt_gemini();
    static std::string prompt_codex();
    static std::string prompt_trinity();
};

} // namespace turbot::core::llm
```

### 关键特性

1. **Provider 智能匹配**: 根据模型 ID 自动选择合适的提示词模板

   - GPT-5 → Codex 风格
   - GPT-4/O1/O3 → OpenAI 风格
   - Claude → Anthropic 风格
   - Gemini → Gemini 风格

2. **环境信息**: 自动包含工作目录、Git 状态、平台信息等

3. **Agent 自定义提示词**: 支持 Agent 级别的提示词覆盖

4. **C++23 特性**: 使用 `std::string::contains()` 和 `std::string_view`

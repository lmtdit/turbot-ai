### 核心接口

```cpp
namespace turbot::core::llm {

/// Provider 类型枚举
enum class ProviderType {
    // OpenAI 兼容
    OpenAI,        // OpenAI GPT models
    Azure,         // Azure OpenAI models
    OpenRouter,    // OpenRouter aggregator
    Groq,          // Groq fast inference
    DeepInfra,     // DeepInfra models
    Together,      // Together AI models
    GitHub,        // GitHub Copilot models
    Cerebras,      // Cerebras fast inference
    DeepSeek,      // DeepSeek models
    XAI,           // xAI Grok models
    Perplexity,    // Perplexity AI models
    Mistral,       // Mistral AI models

    // Anthropic
    Anthropic,     // Anthropic Claude models

    // Google
    Gemini,        // Google Gemini models

    // Amazon
    Bedrock,       // Amazon Bedrock models

    // 其他
    Cohere,        // Cohere models

    // 国产模型
    Bailian,       // 阿里云百炼
    Zhipu,         // 智谱 AI
    Kimi,          // 月之暗面
    Minimax,       // Minimax models

    // Legacy
    Codex,         // OpenAI Codex (legacy)
    Trinity,       // Trinity models
    Other          // 其他/未知
};

/// 系统提示词构建参数
struct SystemPromptParams {
    std::string session_id;
    agent::AgentInfo agent;
    std::string model_id;
    std::string provider_id;
    std::string working_directory;
    bool is_git_repo = false;
    std::string platform;
    std::string current_date;
    std::vector<std::string> custom_prompts;
    std::vector<std::string> user_system_prompts;
};

/// 系统提示词构建器
class SystemPrompt {
public:
    static std::string build(const SystemPromptParams& params);
    static std::string instructions();
    static std::string provider_prompt(std::string_view provider_id, std::string_view model_id);
    static std::string environment(const SystemPromptParams& params);
    static std::string agent_prompt(const agent::AgentInfo& agent);
    static std::string join_prompts(const std::vector<std::string>& parts);

    // Provider 特定模板 (从独立文件加载)
    static std::string prompt_codex();     // GPT-5
    static std::string prompt_beast();     // GPT-4/o1/o3
    static std::string prompt_anthropic(); // Claude
    static std::string prompt_openai();    // OpenAI 兼容
    static std::string prompt_gemini();    // Gemini
    static std::string prompt_qwen();      // Qwen/国产模型
    static std::string prompt_trinity();   // Trinity
};

} // namespace turbot::core::llm
```

### 关键特性

1. **Provider 智能匹配**: 根据模型 ID 自动选择合适的提示词模板

   - GPT-5 → Codex 风格
   - GPT-4/O1/O3 → Beast 风格
   - Claude → Anthropic 风格
   - Gemini → Gemini 风格

2. **环境信息**: 自动包含工作目录、Git 状态、平台信息等

3. **Agent 自定义提示词**: 支持 Agent 级别的提示词覆盖

4. **C++23 特性**: 使用 `std::string::contains()` 和 `std::string_view`

5. **Prompt 文件独立**: 模板存储为独立 Markdown 文件 (详见 [ADR-004](../../decisions/004-prompt-template-independence.md))

   - 支持 `TURBOT_PROMPTS_DIR` 环境变量
   - 内存缓存机制
   - Fallback 内嵌 prompt

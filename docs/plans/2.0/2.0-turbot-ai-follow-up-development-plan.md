### 1.5 Agent 动态加载机制

| 来源        | 路径模式                 | 格式                    |
| ----------- | ------------------------ | ----------------------- |
| 配置文件    | `config.agent.xxx`       | JSON 对象               |
| Agent 目录  | `.turbot/agent/*.md`     | YAML frontmatter + 内容 |
| Agents 目录 | `.turbot/agents/**/*.md` | YAML frontmatter + 内容 |

**Agent MD 文件格式**:

```markdown
---
name: custom-agent
description: Custom agent for specific tasks
mode: subagent
temperature: 0.7
permission:
  read: allow
  edit: deny
---

# Agent Prompt

You are a specialized agent for...
```

**配置覆盖机制**:

```json
{
  "agent": {
    "build": {
      "disable": false,       // 可禁用内置 Agent
      "model": "anthropic/claude-3-sonnet",
      "temperature": 0.5,
      "steps": 50,
      "permission": {...}
    },
    "custom-agent": {
      "prompt": "...",        // 从配置定义新 Agent
      "mode": "subagent"
    }
  }
}
```

**Turbot 当前状态**:

- ❌ 不支持从 MD 文件动态加载
- ❌ 不支持配置文件覆盖 Agent 定义
- ❌ 不支持 disable 内置 Agent
- ❌ Config 模块未与 AgentRegistry 集成

// 核心循环
for (const auto& value : stream.full_stream()) {

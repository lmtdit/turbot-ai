### 权限配置

#### Build Agent

```cpp
// 全允许 + doom_loop=ask
permission::Ruleset build_permission = {
    {"*", "*", PermissionAction::Allow},
    {"doom_loop", "*", PermissionAction::Ask}
};
```

#### Plan Agent

```cpp
// 禁用 edit 工具
permission::Ruleset plan_permission = {
    {"*", "*", PermissionAction::Allow},
    {"edit", "*", PermissionAction::Deny}
};
```

#### Explore Agent

```cpp
// 只允许只读工具
permission::Ruleset explore_permission = {
    {"*", "*", PermissionAction::Deny},
    {"read", "*", PermissionAction::Allow},
    {"grep", "*", PermissionAction::Allow},
    {"glob", "*", PermissionAction::Allow},
    {"list", "*", PermissionAction::Allow}
};
```

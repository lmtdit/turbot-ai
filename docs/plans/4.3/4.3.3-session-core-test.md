---

## C++ 适配说明

| OpenCode (TypeScript)        | Turbot (C++23)                         |
| ---------------------------- | -------------------------------------- |
| `await llm.stream()`         | `std::future<StreamResponse>` 同步等待 |
| `async function test()`      | `TEST_CASE` 同步测试                   |
| `mock.module()` Mock         | 依赖注入 `MockProvider` 接口           |
| `expect(x).resolves.toBe(y)` | `REQUIRE(await_result(x) == y)`        |
| `vi.useFakeTimers()`         | `std::chrono::steady_clock` 控制时间   |

## 目标

验证 Turbot 工具系统核心功能，包括工具注册、编辑、读写、搜索等。

---

## C++ 适配说明

| OpenCode (TypeScript)     | Turbot (C++23)                                  |
| ------------------------- | ----------------------------------------------- |
| `fs.promises.readFile`    | `std::filesystem` + `std::ifstream`             |
| `globby()` 文件匹配       | `std::filesystem::recursive_directory_iterator` |
| `diff` 库差异对比         | 自实现 `diff_match_patch` 或 `dtl` 库           |
| `mock.fs()` 文件系统 Mock | `IFileSystem` 接口注入                          |
| 异步工具执行              | `std::future` + 线程池                          |

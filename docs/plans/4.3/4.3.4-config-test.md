## 目标

## C++ 适配说明

| OpenCode (TypeScript) | Turbot (C++23)                          |
| --------------------- | --------------------------------------- |
| JSON 配置解析         | `nlohmann_json` 自动序列化              |
| 配置合并              | 递归合并算法                            |
| 配置验证              | Schema 验证 + 类型检查                  |
| 热重载                | `std::filesystem::last_write_time` 轮询 |
| 配置文件监视          | `inotify` (Linux) / `FSEvents` (macOS)  |

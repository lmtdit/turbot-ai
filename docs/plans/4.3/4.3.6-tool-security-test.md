# v4.3.6 工具安全测试

> **依赖**: 4.3.5 (工具核心测试)
> **预估工时**: 1 天
> **状态**: 待执行

---

## 目标

验证 Turbot 工具系统安全功能，包括 Bash 执行、外部目录访问、路径遍历防护。

---

## C++ 适配说明

| OpenCode (TypeScript) | Turbot (C++23)                      |
| --------------------- | ----------------------------------- |
| `child_process.spawn` | `std::process` 或 `boost::process`  |
| Shell 命令注入检测    | 正则表达式 + 黑名单                 |
| 路径规范化            | `std::filesystem::weakly_canonical` |
| 符号链接检测          | `std::filesystem::symlink_status`   |
| 权限请求 UI           | `IPermissionAsker` 接口注入         |

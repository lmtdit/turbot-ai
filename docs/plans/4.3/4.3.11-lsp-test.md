## C++ 适配说明

| OpenCode (TypeScript)   | Turbot (C++23)                             |
| ----------------------- | ------------------------------------------ |
| `vscode-languageclient` | 自实现 LSP 客户端                          |

| LSP 位置解析            | `std::filesystem::path` + 行列计算         |

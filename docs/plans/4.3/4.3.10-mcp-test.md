## 目标

验证 Turbot MCP (Model Context Protocol) 协议实现。

---

## C++ 适配说明

| OpenCode (TypeScript) | Turbot (C++23)                             |
| --------------------- | ------------------------------------------ |
| `EventSource` SSE     | 自实现 SSE 客户端或 `cpr` 库               |
| `WebSocket` 连接      | `boost::beast::websocket` 或 `ixwebsocket` |
| `open()` 打开浏览器   | `std::system()` 调用系统命令               |
| OAuth 回调服务器      | `boost::asio` 简易 HTTP 服务器             |
| JSON-RPC 2.0          | `nlohmann_json` + 自实现协议层             |

## C++ 适配说明

| OpenCode (TypeScript) | Turbot (C++23)                   |
| --------------------- | -------------------------------- |
| `better-sqlite3`      | `sqlite3` C API 或 `SQLiteCpp`   |
| 数据库迁移            | 手动 SQL 迁移脚本                |
| JSON Schema 验证      | `nlohmann_json` + `valijson`     |
| `globby` 文件匹配     | `std::filesystem` + `std::regex` |
| `micromatch` 通配符   | 自实现 glob 匹配器               |
| `p-limit` 并发限制    | `std::semaphore` (C++20)         |

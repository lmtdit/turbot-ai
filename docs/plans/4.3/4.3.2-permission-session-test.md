## 目标

通过参考 OpenCode 测试机制，验证 Turbot 权限系统和会话分页功能的正确性。

---

## C++ 适配说明

| OpenCode (TypeScript) | Turbot (C++23)                |
| --------------------- | ----------------------------- |
| 权限规则对象          | `PermissionRule` 结构体       |
| `glob` 模式匹配       | `std::regex` 或 `fnmatch`     |
| `~` 路径展开          | `std::getenv("HOME")`         |
| 分页游标              | `std::optional<int64_t>` 游标 |
| 异步权限请求          | 同步 `ask()` + `std::promise` |

### 任务 1: 权限系统测试 - fromConfig

**目标**: 验证权限配置解析功能

**参考**: `next.test.ts` 中的 `fromConfig` 测试用例

**测试用例**:

| 用例名                           | 测试内容                 | 预期结果                                            |
| -------------------------------- | ------------------------ | --------------------------------------------------- |
| FromConfig_StringBecomesWildcard | 字符串配置转为通配符规则 | `{"bash": "allow"}` → `bash: *: allow`              |
| FromConfig_ObjectConvertsToRules | 对象配置转为规则数组     | `{"bash": {"*": "allow", "rm": "deny"}}` → 2 条规则 |
| FromConfig_ExpandsTilde          | 展开 `~` 到 home 目录    | `~/projects/*` → `/home/user/projects/*`            |

**输出文件**:

- `tests/v2/permission/permission_test_v2.cpp`

**验证标准**:

- [ ] 3 个 fromConfig 测试用例通过

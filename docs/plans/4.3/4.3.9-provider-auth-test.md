## 目标

验证 Turbot Provider 认证系统，包括 OAuth、API Key、Copilot 认证等。

---

## C++ 适配说明

| OpenCode (TypeScript) | Turbot (C++23)                  |
| --------------------- | ------------------------------- |
| OAuth 流程            | `cpr` 库 HTTP 请求 + 回调服务器 |
| Token 存储            | 加密文件存储或系统 Keychain     |
| 设备码流程            | 轮询授权端点                    |
| Token 刷新            | 后台定时器 + 自动刷新           |

## P0-3：general agent

> **状态**：✅ 已完成
> **依赖**：P0-2（task 工具）
> **参考实现**：OpenCode `src/agent/agent.ts` general agent
> **实现位置**：`libs/core/src/agent/agent_loader.cpp:50-66`（ConfigurableAgent）
> **测试位置**：`tests/unit/agent_test.cpp:1033-1075`

### 问题描述

Turbot 缺少通用子任务 Agent，无法并行执行多单元工作。OpenCode 的 general agent 是 subagent 模式，用于处理复杂问题和多步骤任务。

### OpenCode 实现参考

```typescript
// OpenCode agent.ts
general: {
  name: "general",
  description: `General-purpose agent for researching complex questions
                and executing multi-step tasks. Use this agent to execute
                multiple units of work in parallel.`,
  permission: PermissionNext.merge(
    defaults,
    PermissionNext.fromConfig({
      todoread: "deny",
      todowrite: "deny",
    }),
    user,
  ),
  options: {},
  mode: "subagent",
  native: true,
},
```

### 修复方向

1. 创建 `libs/core/src/agent/builtin/general_agent.cpp`
2. 实现 GeneralAgent：
   - mode: subagent（只能被 task 工具调用）
   - 权限：todoread/todowrite deny
   - 支持并行执行多个子任务
   - 复用 v4.0 的 LLM 接入逻辑
3. 注册到 `AgentRegistry`

### 实现骨架

```cpp
// general_agent.cpp
class GeneralAgent : public Agent {
public:
    GeneralAgent() {
        info_.name = "general";
        info_.description = "General-purpose agent for researching complex "
                           "questions and executing multi-step tasks.";
        info_.mode = AgentMode::Subagent;
        info_.native = true;

        // 权限配置
        info_.permission = PermissionRuleset::merge(
            PermissionRuleset::defaults(),
            PermissionRuleset::from_config({
                {"todoread", "deny"},
                {"todowrite", "deny"}
            })
        );
    }

    ExecuteResult execute(const ExecuteParams& params) override {
        // 1. 获取 Provider
        auto& pm = ProviderManager::instance();
        auto provider_opt = pm.get_default_provider();
        if (!provider_opt) {
            return ExecuteResult::error("No provider configured");
        }

        // 2. 创建子 SessionLoop
        SessionLoop sub_loop(params.session_id);
        sub_loop.set_provider(provider_opt->get());
        sub_loop.set_model(pm.get_default_model());
        sub_loop.set_agent(shared_from_this());

        // 3. 执行
        auto result = sub_loop.run(params.prompt);
        if (result == LoopResult::Error) {
            return ExecuteResult::error("LLM execution failed");
        }

        // 4. 返回结果
        auto last_text = sub_loop.messages().back().get_text();
        return ExecuteResult::ok(last_text);
    }
};
```

## P1-1：compaction agent

> **状态**：✅ 已完成
> **依赖**：无
> **参考实现**：OpenCode `src/agent/agent.ts` compaction agent
> **实现位置**：`libs/core/src/agent/agent_loader.cpp:68-82`（ConfigurableAgent）
> **测试位置**：`tests/unit/agent_test.cpp:1081-1126`

### 问题描述

Turbot 缺少会话压缩 Agent，长会话时上下文占用过大。OpenCode 的 compaction agent 是 hidden 模式，用于压缩会话历史，减少 token 消耗。

### OpenCode 实现参考

```typescript
// OpenCode agent.ts
compaction: {
  name: "compaction",
  mode: "primary",
  native: true,
  hidden: true,
  prompt: PROMPT_COMPACTION,
  permission: PermissionNext.merge(
    defaults,
    PermissionNext.fromConfig({
      "*": "deny",
    }),
    user,
  ),
  options: {},
},
```

### 修复方向

1. 创建 `libs/core/src/agent/builtin/compaction_agent.cpp`
2. 实现 CompactionAgent：
   - mode: primary
   - hidden: true（不在 Agent 列表中显示）
   - 权限：所有工具 deny
   - 实现会话消息压缩逻辑
   - 保留关键信息，删除冗余内容
3. 注册到 `AgentRegistry`

### 实现骨架

```cpp
// compaction_agent.cpp
class CompactionAgent : public Agent {
public:
    CompactionAgent() {
        info_.name = "compaction";
        info_.mode = AgentMode::Primary;
        info_.native = true;
        info_.hidden = true;
        info_.prompt = load_compaction_prompt(); // 从文件加载

        // 权限配置：所有工具 deny
        info_.permission = PermissionRuleset::merge(
            PermissionRuleset::defaults(),
            PermissionRuleset::from_config({
                {"*", "deny"}
            })
        );
    }

    ExecuteResult execute(const ExecuteParams& params) override {
        // 1. 获取 Provider
        auto& pm = ProviderManager::instance();
        auto provider_opt = pm.get_default_provider();
        if (!provider_opt) {
            return ExecuteResult::error("No provider configured");
        }

        // 2. 创建 SessionLoop
        SessionLoop loop(params.session_id);
        loop.set_provider(provider_opt->get());
        loop.set_model(pm.get_default_model());
        loop.set_agent(shared_from_this());

        // 3. 执行压缩
        auto result = loop.run(params.prompt);
        if (result == LoopResult::Error) {
            return ExecuteResult::error("Compaction failed");
        }

        // 4. 返回压缩后的摘要
        auto summary = loop.messages().back().get_text();
        return ExecuteResult::ok(summary);
    }
};
```

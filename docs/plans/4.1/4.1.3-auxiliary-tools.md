## P1-2：todo 工具

> **状态**：✅ 已完成
> **依赖**：无
> **参考实现**：OpenCode `src/tool/todo.ts`
> **实现位置**：`libs/core/src/tool/builtin/todo_tool.cpp`

### 问题描述

```typescript

export const TodoTool = Tool.define('todo', {
  description: DESCRIPTION,
  parameters: z.object({
    todos: z.array(
      z.object({
        content: z.string(),
        status: z.enum(['pending', 'in_progress', 'completed']),
      }),
    ),
  }),
  async execute(params, ctx) {
    // 读取或写入 todo 列表
  },
})
```

### 修复方向

1. 创建 `libs/core/src/tool/builtin/todo_tool.cpp`
2. 实现 TodoTool：
   - todoread：读取当前任务列表
   - todowrite：写入/更新任务列表
   - 支持任务状态（pending/in_progress/completed）
   - 任务持久化到 Session
3. 注册到 `ToolRegistry`

### 实现骨架

```cpp
// todo_tool.cpp
ToolResult TodoTool::execute(const json& input, const ToolContext& ctx) {
    std::string action = input.value("action", "read");

    if (action == "read") {
        // 读取任务列表
        auto todos = Session::get_todos(ctx.session_id);
        json result = json::array();
        for (const auto& todo : todos) {
            result.push_back({
                {"id", todo.id},
                {"content", todo.content},
                {"status", todo.status}
            });
        }
        return ToolResult::ok(result.dump(2));
    }
    else if (action == "write") {
        // 写入任务列表
        std::vector<TodoItem> todos;
        for (const auto& item : input["todos"]) {
            todos.push_back({
                .id = generate_id(),
                .content = item["content"],
                .status = item["status"]
            });
        }
        Session::set_todos(ctx.session_id, todos);
        return ToolResult::ok("Todos updated successfully");
    }

    return ToolResult::error("Invalid action: " + action);
}
```

ToolResult SkillTool::execute(const json& input, const ToolContext& ctx) {
    std::string skill_name = input["skill"];
    json skill_input = input.value("input", json::object());

    // 1. 加载技能定义

        return ToolResult::error("Skill not found: " + skill_name);

    return result;

   - plan_exit：退出计划模式，输出结构化计划文档

3. 注册到 `ToolRegistry`

### 实现骨架

```cpp
// plan_tool.cpp
ToolResult PlanTool::execute(const json& input, const ToolContext& ctx) {
    std::string action = input["action"];

    if (action == "enter") {
        // 进入计划模式
        Session::set_mode(ctx.session_id, SessionMode::Plan);
        return ToolResult::ok("Entered plan mode. You can now create a plan.");
    }
    else if (action == "exit") {
        // 退出计划模式并保存
        std::string plan = input["plan"];
        std::string plan_path = save_plan(ctx.session_id, plan);
        Session::set_mode(ctx.session_id, SessionMode::Normal);
        return ToolResult::ok("Plan saved to: " + plan_path);
    }

    return ToolResult::error("Invalid action: " + action);
}
```

### 实现骨架

```cpp
// question_tool.cpp
ToolResult QuestionTool::execute(const json& input, const ToolContext& ctx) {
    std::string question = input["question"];

    // 1. 发布问题事件
    QuestionInfo info;
    info.id = QuestionID::generate();
    info.session_id = ctx.session_id;
    info.message_id = ctx.message_id;
    info.question = question;
    info.time_created = std::chrono::system_clock::now();

    // 2. 等待用户回复
    auto answer = wait_for_answer(info.id, 300000); // 5分钟超时

    if (!answer) {
        return ToolResult::error("Question timeout");
    }

    return ToolResult::ok(answer.value());
}
```

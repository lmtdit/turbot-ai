## 一、P0-1：websearch 工具

> **状态**：📋 待启动
> **依赖**：无
> **参考实现**：OpenCode `src/tool/websearch.ts`

### 问题描述

Turbot 缺少网络搜索工具，无法通过搜索引擎获取实时信息。OpenCode 的 `websearch.ts` 集成了搜索 API，支持网络搜索并返回结构化结果。

### 修复方向

1. 创建 `libs/core/src/tool/builtin/websearch_tool.cpp`
2. 接入搜索 API（如 Exa、Serper、或自建）
3. 支持搜索结果解析和摘要生成
4. 注册到 `ToolRegistry`

### 验收标准

- [ ] 编译通过
- [ ] websearch 工具在 ToolRegistry 中注册
- [ ] 搜索请求返回有效结果
- [ ] 结果格式符合 ToolResult 规范
- [ ] 单元测试覆盖率 ≥ 85%

## 二、P0-2：task 工具

> **状态**：📋 待启动
> **依赖**：无
> **参考实现**：OpenCode `src/tool/task.ts`

### 问题描述

Turbot 缺少子任务派发工具，无法将复杂任务分解为子任务并派发给 Agent 执行。OpenCode 的 `task.ts` 支持通过 TaskTool 调用子 Agent 完成子任务。

### 修复方向

1. 创建 `libs/core/src/tool/builtin/task_tool.cpp`
2. 实现 TaskTool，支持：
   - 子任务描述解析
   - 调用 Agent::execute() 执行子任务
   - 收集子任务结果并汇总
3. 注册到 `ToolRegistry`

### 验收标准

- [ ] 编译通过
- [ ] task 工具在 ToolRegistry 中注册
- [ ] 可派发子任务给指定 Agent
- [ ] 子任务结果正确汇总返回
- [ ] 单元测试覆盖率 ≥ 85%

## 总结

v4.1 计划聚焦于 **工具系统和 Agent 系统的核心功能补全**，预计将：

- 工具系统对齐度从 55% 提升至 85%（新增 6 个工具）

## P2-1：RustAnalyzer LSP

> **状态**：✅ 已完成
> **依赖**：无
> **参考实现**：OpenCode `src/lsp/server.ts` RustAnalyzer
> **实现位置**：`libs/core/src/lsp/builtin_servers.cpp:297-338`

### 问题描述

Turbot 缺少 Rust 语言服务器支持。Rust 是高需求语言，RustAnalyzer 是官方推荐的 LSP，支持 Cargo workspace、类型推断、代码补全等功能。

### OpenCode 实现参考

```typescript
// OpenCode server.ts
export const RustAnalyzer: Info = {
  id: 'rust',
  root: async (root) => {
    const crateRoot = await NearestRoot(['Cargo.toml', 'Cargo.lock'])(root)
    if (crateRoot === undefined) return undefined

    // 查找 workspace 根
    let currentDir = crateRoot
    while (currentDir !== path.dirname(currentDir)) {
      const cargoTomlPath = path.join(currentDir, 'Cargo.toml')
      const cargoTomlContent = await Filesystem.readText(cargoTomlPath)
      if (cargoTomlContent.includes('[workspace]')) {
        return currentDir
      }
      currentDir = path.dirname(currentDir)
    }
    return crateRoot
  },
  extensions: ['.rs'],
  async spawn(root) {
    const bin = which('rust-analyzer')
    if (!bin) {
      log.info('rust-analyzer not found in path, please install it')
      return
    }
    return {
      process: spawn(bin, { cwd: root }),
    }
  },
}
```

### 修复方向

1. 在 `libs/core/src/lsp/builtin_servers.cpp` 中添加 `make_rust_analyzer_server()`
2. 实现：
   - root: 查找 Cargo.toml/Cargo.lock，支持 workspace 检测
   - extensions: [".rs"]
   - spawn: `rust-analyzer`（无参数）
3. 注册到 LSPManager

### 实现骨架

```cpp
// builtin_servers.cpp
LSPServerInfo make_rust_analyzer_server(const std::string& workspace_root) {
    LSPServerInfo info;
    info.id = "rust";
    info.extensions = {".rs"};
    info.global = false;

    // Root 函数：查找 Cargo workspace 根
    info.root = [](const std::string& file, const std::string& root)
        -> std::optional<std::string>
    {
        // 1. 查找最近的 Cargo.toml
        auto crate_root = nearest_root(file, {"Cargo.toml", "Cargo.lock"}, root);
        if (!crate_root) return std::nullopt;

        // 2. 向上查找 workspace 根
        fs::path current = *crate_root;
        while (current != current.parent_path()) {
            fs::path cargo_toml = current / "Cargo.toml";
            if (fs::exists(cargo_toml)) {
                std::ifstream f(cargo_toml);
                std::string content((std::istreambuf_iterator<char>(f)),
                                    std::istreambuf_iterator<char>());
                if (content.find("[workspace]") != std::string::npos) {
                    return current.string();
                }
            }
            current = current.parent_path();
        }
        return crate_root;
    };

    // Spawn 函数
    info.spawn = [](const std::string& root_dir) -> std::optional<LSPServerHandle> {
        std::string bin = which("rust-analyzer");
        if (bin.empty()) {
            TURBOT_LOG_INFO("rust-analyzer not found, please install it");
            return std::nullopt;
        }
        return spawn_process({bin}, root_dir);
    };

    return info;
}
```

## P2-2：Svelte/Astro LSP

> **状态**：✅ 已完成
> **依赖**：无
> **参考实现**：OpenCode `src/lsp/server.ts` Svelte/Astro
> **实现位置**：`libs/core/src/lsp/builtin_servers.cpp:340-361`

### 问题描述

Turbot 缺少 Svelte 和 Astro 前端框架 LSP 支持。这两个框架在前端生态中需求较高，Svelte 以编译时优化著称，Astro 是新兴的静态站点框架。

### OpenCode 实现参考

```typescript
// OpenCode server.ts - Svelte
export const Svelte: Info = {
  id: "svelte",
  extensions: [".svelte"],
  root: NearestRoot(["package-lock.json", "bun.lockb", "bun.lock",
                     "pnpm-lock.yaml", "yarn.lock"]),
  async spawn(root) {
    let binary = which("svelteserver")
    const args: string[] = []
    if (!binary) {
      const js = path.join(Global.Path.bin, "node_modules",
                           "svelte-language-server", "bin", "server.js")
      if (!(await Filesystem.exists(js))) {
        if (Flag.OPENCODE_DISABLE_LSP_DOWNLOAD) return
        await Process.spawn([BunProc.which(), "install",
                            "svelte-language-server"], {...})
      }
      binary = BunProc.which()
      args.push("run", js)
    }
    args.push("--stdio")
    return { process: spawn(binary, args, {...}) }
  },
}
```

# Turbot-AI 基础架构实现计划

## 1. 概述

本计划是 Turbot-AI 项目的第一阶段实现，旨在建立完整的项目基础架构和核心基础设施。这是整个项目的地基，后续所有模块都将依赖于此。

### 1.1 目标

- 建立标准化的项目结构和构建系统
- 实现核心工具库（JSON、字符串、加密）
- 建立日志系统
- 实现配置管理
- 建立事件总线系统

### 1.2 依赖关系

- **前置依赖**: 无
- **后置依赖**: 存储层、网络层、所有核心组件

### 1.3 交付物

- 完整的 CMake 构建配置
- Conan 依赖管理配置
- 工具库实现
- 日志系统实现
- 配置管理系统
- 事件总线实现
- 基础测试框架

**实现要点**:
```cpp
void init(const std::string& log_file, const std::string& level) {
    // 创建控制台sink
    auto console_sink = std::make_shared<spdlog::sinks::stdout_color_sink_mt>();
    console_sink->set_level(spdlog::level::info);
    console_sink->set_pattern("[%Y-%m-%d %H:%M:%S.%e] [%^%l%$] [%s:%#] %v");

    std::vector<spdlog::sink_ptr> sinks{console_sink};

    // 创建文件sink
    if (!log_file.empty()) {
        auto file_sink = std::make_shared<spdlog::sinks::rotating_file_sink_mt>(
            log_file, 1024 * 1024 * 10, 3);
        file_sink->set_level(spdlog::level::trace);
        file_sink->set_pattern("[%Y-%m-%d %H:%M:%S.%e] [%l] [%t] [%s:%#] %v");
        sinks.push_back(file_sink);
    }

    // 创建logger
    auto logger = std::make_shared<spdlog::logger>("turbot", sinks.begin(), sinks.end());
    logger->set_level(level_to_spdlog_level(level));
    logger->flush_on(spdlog::level::warn);

    // 设置为默认logger
    spdlog::set_default_logger(logger);
}
```

```cpp
class Config {
public:
    // 单例访问

    // 设置配置值

    void set(const std::string& key, const T& value);

    // 监听配置变化

    std::string watch(const std::string& key, ChangeCallback callback);
    void unwatch(const std::string& key, const std::string& watch_id);

private:

    nlohmann::json config_;
    std::unordered_map<std::string, std::vector<std::pair<std::string, ChangeCallback>>> watchers_;
```

### 4.5 事件总线

**文件**: `libs/infra/event/event_bus.hpp`, `event_bus.cpp`

**功能**:
- 发布-订阅模式
- 类型安全的事件处理
- 异步事件分发
- 事件过滤

**接口**:
```cpp
namespace turbot::infra::event {

template<typename T>
struct Event {
    std::string name;
    T data;
    int64_t timestamp;
    std::string source;
};

template<typename T>
using EventHandler = std::function<Task<void>(const Event<T>&)>;

class EventBus {
public:
    // 单例访问
    static EventBus& instance();

    // 发布事件
    template<typename T>
    Task<void> publish(const std::string& name, T data,
                        const std::string& source = "turbot");

    // 订阅事件
    template<typename T>
    std::string subscribe(const std::string& name, EventHandler<T> handler,
                           const std::string& filter = "");

    // 取消订阅
    void unsubscribe(const std::string& name, const std::string& handler_id);

    // 获取订阅者数量
    size_t subscriber_count(const std::string& name) const;

    // 列出所有事件
    std::vector<std::string> list_events() const;

private:
    EventBus() = default;

    struct HandlerEntry {
        std::string id;
        std::string filter;
        std::function<Task<void>(const std::any&)> handler;
    };

    std::unordered_map<std::string, std::vector<HandlerEntry>> handlers_;
    mutable std::shared_mutex mutex_;
};

} // namespace turbot::infra::event
```

**实现要点**:
```cpp

        .source = source
    };

    std::shared_lock lock(mutex_);
```

```cpp
// tests/unit/utils/string_utils_test.cpp
#include <catch2/catch_test_macros.hpp>
#include "turbot/utils/string/string_utils.hpp"

TEST_CASE("string::split", "[utils][string]") {
    SECTION("basic split") {
        auto result = turbot::utils::string::split("a,b,c", ",");
        REQUIRE(result.size() == 3);
        REQUIRE(result[0] == "a");
        REQUIRE(result[1] == "b");
        REQUIRE(result[2] == "c");
    }

    SECTION("empty delimiter") {
        auto result = turbot::utils::string::split("abc", "");
        REQUIRE(result.size() == 1);
        REQUIRE(result[0] == "abc");
    }
}
```

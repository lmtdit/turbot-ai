## 实施步骤

### Step 1: API 错误重试验证

```cpp
TEST_CASE("ERR-01: API error auto retry", "[integration][error]") {
    auto session = session::Session::create({...});
    auto agent = agent::AgentRegistry::instance().get("build");

    // Mock provider 前两次失败，第三次成功
    auto mock_provider = std::make_shared<MockProvider>();
    mock_provider->set_error_sequence({
        ProviderError::RateLimitExceeded,
        ProviderError::RateLimitExceeded,
        std::nullopt  // 成功
    });

    session::SessionLoop loop(*session, agent);
    loop.set_provider(mock_provider);

    auto result = loop.run("Hello");

    CHECK(result == session::LoopResult::Stop);
    CHECK(mock_provider->call_count() == 3);  // 重试了2次
    CHECK(loop.retry_count() == 2);
}
```

### Step 2: 网络超时恢复验证

```cpp
TEST_CASE("ERR-02: Network timeout recovery", "[integration][error]") {
    auto session = session::Session::create({...});
    auto agent = agent::AgentRegistry::instance().get("build");

    // Mock provider 模拟超时
    auto mock_provider = std::make_shared<MockProvider>();
    mock_provider->set_timeout_behavior(
        /* timeout_after */ 2,
        /* then_succeed */ true
    );

    session::SessionLoopConfig config;
    config.timeout_seconds = 5;
    config.retry_on_timeout = true;

    session::SessionLoop loop(*session, agent, config);
    loop.set_provider(mock_provider);

    auto result = loop.run("Hello");

    CHECK(result == session::LoopResult::Stop);
}
```

### Step 3: 权限拒绝处理验证

```cpp
TEST_CASE("ERR-03: Permission denied handling", "[integration][error]") {
    auto session = session::Session::create({...});
    auto agent = agent::AgentRegistry::instance().get("build");

    // 配置权限模式为 deny
    session->set_permission_mode(PermissionMode::Deny);

    session::SessionLoop loop(*session, agent);

    // 尝试执行需要权限的操作
    auto result = loop.run("Delete all files");

    // 验证权限被拒绝
    CHECK(loop.had_permission_denial());
    CHECK_FALSE(loop.had_unauthorized_execution());
}
```

### Step 4: 工具执行错误验证

```cpp
TEST_CASE("ERR-04: Tool execution error", "[integration][error]") {
    auto session = session::Session::create({...});
    auto agent = agent::AgentRegistry::instance().get("build");

    // Mock provider 返回工具调用
    auto mock_provider = std::make_shared<MockProvider>();
    mock_provider->set_next_response(ChatMessage::assistant_with_tool_call(
        "bash",
        {{"command", "exit 1"}}  // 故意失败
    ));

    session::SessionLoop loop(*session, agent);
    loop.set_provider(mock_provider);

    auto result = loop.run("Run a failing command");

    // 验证错误被正确处理
    CHECK(loop.had_tool_error());
    CHECK_FALSE(loop.had_unhandled_exception());

    // 验证错误信息被记录
    auto errors = loop.get_errors();
    REQUIRE_FALSE(errors.empty());
    CHECK(errors[0].type == ErrorType::ToolExecution);
}
```

## 错误类型定义

```cpp
enum class ErrorType {
    NetworkError,
    ProviderError,
    ToolExecutionError,
    PermissionDenied,
    TimeoutError,
    UnknownError
};

struct ErrorRecord {
    ErrorType type;
    std::string message;
    std::chrono::system_clock::time_point timestamp;
    bool recovered;
};
```

## 重试策略

| 错误类型           | 重试次数 | 退避策略              |
| ------------------ | -------- | --------------------- |
| RateLimitExceeded  | 3        | 指数退避 (1s, 2s, 4s) |
| NetworkError       | 2        | 固定间隔 (2s)         |
| TimeoutError       | 1        | 无等待                |
| PermissionDenied   | 0        | 不重试                |
| ToolExecutionError | 0        | 不重试                |

## 错误恢复流程

```
错误发生
    ↓
记录错误日志
    ↓
判断是否可重试
    ├── 可重试 → 执行退避等待 → 重试
    └── 不可重试 → 返回错误给用户
```

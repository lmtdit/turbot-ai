## 默认 Provider 配置

### 阿里云百炼 (Bailian)

项目默认使用阿里云百炼 Provider 进行核心流程验证和调试。

**配置路径**: `.turbot/turbot.json`

**API 基础 URL**: `https://dashscope.aliyuncs.com/compatible-mode/v1`

**环境变量**: `DASHSCOPE_API_KEY`

## 目标

验证消息持久化系统正常工作，确保会话数据可靠存储和恢复。

| 场景       | 描述                |

| PERSIST-01 | 消息保存到数据库    |
| PERSIST-02 | 会话恢复后消息完整  |
| PERSIST-03 | Part 流式更新持久化 |
| PERSIST-04 | 压缩后消息状态正确  |

## 实施步骤

### Step 1: 验证数据库初始化

```cpp
TEST_CASE("PERSIST-01: Message saved to database", "[integration][persistence]") {
    // 1. 创建会话
    auto session = session::Session::create({
        .project_id = "persist-test",
        .slug = "test-session",
        .directory = "/tmp/persist-test"
    });

    // 2. 创建消息
    auto msg = session->create_message(ChatRole::User, "Hello");

    // 3. 验证数据库记录
    auto db = storage::Database::instance();
    auto records = db.query(
        "SELECT * FROM messages WHERE session_id = ?",
        session->id()
    );

    REQUIRE(records.size() == 1);
    CHECK(records[0]["content"] == "Hello");
}
```

### Step 2: 验证会话恢复

```cpp
TEST_CASE("PERSIST-02: Session recovery with complete messages", "[integration][persistence]") {
    // 1. 创建并保存会话
    std::string session_id;
    {
        auto session = session::Session::create({...});
        session_id = session->id();
        session->create_message(ChatRole::User, "Question");
        session->create_message(ChatRole::Assistant, "Answer");
    }

    // 2. 恢复会话
    auto recovered = session::Session::load(session_id);
    REQUIRE(recovered.has_value());

    // 3. 验证消息完整
    auto messages = recovered->get_messages();
    REQUIRE(messages.size() == 2);
    CHECK(messages[0].content == "Question");
    CHECK(messages[1].content == "Answer");
}
```

### Step 3: 验证 Part 流式更新

```cpp
TEST_CASE("PERSIST-03: Part streaming persistence", "[integration][persistence]") {
    auto session = session::Session::create({...});
    auto msg = session->create_message(ChatRole::Assistant, "");

    // 模拟流式 Part 更新
    for (int i = 0; i < 5; i++) {
        msg.add_part(Part::create_text_delta("chunk" + std::to_string(i)));
    }

    // 验证 Part 持久化
    auto parts = msg.get_parts();
    REQUIRE(parts.size() == 5);
}
```

### Step 4: 验证压缩状态

```cpp
TEST_CASE("PERSIST-04: Compacted message state correct", "[integration][persistence]") {
    auto session = session::Session::create({...});

    // 创建多条消息
    for (int i = 0; i < 10; i++) {
        session->create_message(ChatRole::User, "Message " + std::to_string(i));
    }

    // 执行压缩
    session->compact_messages(5);

    // 验证压缩状态
    auto db = storage::Database::instance();
    auto compacted = db.query(
        "SELECT * FROM messages WHERE session_id = ? AND compacted = 1",
        session->id()
    );

    CHECK(compacted.size() == 5); // 前5条被压缩
}
```

# 2.5.4 多 Agent 协作验证

> **工时**: 1 天
> **测试类型**: 集成测试
> **依赖**: 2.5.1 端到端流程验证
> **状态**: ✅ 已完成

## 目标

验证多 Agent 协作机制正常工作，确保主 Agent 可以调用子 Agent 并正确处理结果。

## 验证场景

| 场景     | 描述                  |
| -------- | --------------------- |
| AGENT-01 | 主 Agent 调用子 Agent |
| AGENT-02 | 子 Agent 权限隔离     |
| AGENT-03 | 子 Agent 结果返回     |
| AGENT-04 | 嵌套 Agent 调用       |

## 实施步骤

### Step 1: TaskTool 验证

```cpp
TEST_CASE("AGENT-01: Main Agent calls Sub Agent", "[integration][agent]") {
    // 1. 创建主会话
    auto main_session = session::Session::create({
        .project_id = "agent-test",
        .slug = "main-session",
        .directory = "/tmp/agent-test"
    });
    auto main_agent = agent::AgentRegistry::instance().get("build");

    // 2. 执行需要子 Agent 的任务
    session::SessionLoop loop(*main_session, main_agent);

    // 3. Mock provider 返回 task 工具调用
    auto mock_provider = std::make_shared<MockProvider>();
    mock_provider->set_next_response(ChatMessage::assistant_with_tool_call(
        "task",
        {
            {"subagent_type", "explore"},
            {"prompt", "Explore the codebase structure"}
        }
    ));

    // 4. 验证子 Agent 被创建和执行
    auto result = loop.run("Explore the codebase structure");

    // 5. 验证结果包含子 Agent 输出
    CHECK(result == session::LoopResult::Stop);
    CHECK(loop.had_subagent_call());
}
```

### Step 2: 权限隔离验证

```cpp
TEST_CASE("AGENT-02: Sub Agent permission isolation", "[integration][agent]") {
    // 主 Agent 有完整权限
    auto main_agent = agent::AgentRegistry::instance().get("build");

    // 子 Agent 只有只读权限
    auto sub_agent = agent::AgentRegistry::instance().get("explore");

    // 验证权限差异
    CHECK(main_agent->has_permission("write_file"));
    CHECK_FALSE(sub_agent->has_permission("write_file"));

    CHECK(main_agent->has_permission("bash"));
    CHECK_FALSE(sub_agent->has_permission("bash:rm"));
}
```

### Step 3: 结果返回验证

```cpp
TEST_CASE("AGENT-03: Sub Agent result return", "[integration][agent]") {
    auto session = session::Session::create({...});
    auto agent = agent::AgentRegistry::instance().get("build");

    session::SessionLoop loop(*session, agent);

    // 执行子任务
    auto result = loop.run("Find all TODO comments in the codebase");

    // 验证子 Agent 结果被正确返回
    auto messages = loop.messages();
    bool has_subagent_result = false;

    for (const auto& msg : messages) {
        if (msg.has_tool_result("task")) {
            has_subagent_result = true;
            CHECK_FALSE(msg.tool_result("task").empty());
        }
    }

    CHECK(has_subagent_result);
}
```

### Step 4: 嵌套调用验证

```cpp
TEST_CASE("AGENT-04: Nested Agent calls", "[integration][agent]") {
    auto session = session::Session::create({...});
    auto agent = agent::AgentRegistry::instance().get("build");

    session::SessionLoop loop(*session, agent);

    // 主 Agent -> 子 Agent -> 孙 Agent
    auto result = loop.run("Analyze the project and create a summary");

    // 验证嵌套深度
    CHECK(loop.max_agent_depth() <= 3); // 最多3层嵌套

    // 验证所有层级结果正确返回
    CHECK(loop.all_subagent_results_valid());
}
```

## Agent 类型定义

| Agent 类型 | 权限级别    | 用途                 |
| ---------- | ----------- | -------------------- |
| `build`    | 完整        | 代码生成、修改、执行 |
| `plan`     | 只读 + 规划 | 分析、规划、设计     |
| `explore`  | 只读        | 代码探索、搜索       |

## TaskTool 接口

```cpp
class TaskTool : public Tool {
public:
    struct Parameters {
        std::string subagent_type;  // "explore", "plan", etc.
        std::string prompt;
        std::optional<std::string> working_directory;
    };

    ToolResult execute(const Parameters& params) override {
        // 1. 创建子 Agent
        auto sub_agent = AgentRegistry::instance().get(params.subagent_type);

        // 2. 创建子会话
        auto sub_session = Session::create({...});

        // 3. 执行子任务
        SessionLoop sub_loop(*sub_session, sub_agent);
        auto result = sub_loop.run(params.prompt);

        // 4. 返回结果
        return ToolResult::success(sub_session->get_final_output());
    }
};
```

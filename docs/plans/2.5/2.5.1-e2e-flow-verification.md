> **工时**: 1 天
> **测试类型**: 集成测试
> **依赖**: 2.0 全部完成

## 目标

验证从用户输入到 LLM 响应的完整链路正常工作，确保核心流程端到端可用。

## 验证场景

| 场景   | 描述       | 预期结果                                  |
| ------ | ---------- | ----------------------------------------- |
| E2E-01 | 简单问答   | 用户输入 → LLM 响应 → 结束                |
| E2E-02 | 工具调用   | 用户输入 → LLM 调用工具 → 执行 → 返回结果 |
| E2E-03 | 多轮对话   | 用户输入 → 响应 → 追问 → 响应             |
| E2E-04 | Agent 切换 | 切换 Agent → 使用不同 prompt              |
| E2E-05 | 流式中断   | 用户中断 → 正确停止                       |
| E2E-06 | 上下文压缩 | 超过阈值 → 自动压缩                       |
| E2E-07 | 错误重试   | API 错误 → 自动重试                       |
| E2E-08 | 死循环检测 | 相同工具 3 次 → 触发检测                  |

## 测试代码

```cpp
// tests/integration/e2e_test.cpp

#include <catch2/catch_test_macros.hpp>
#include <turbot/core/session/session_loop.hpp>
#include <turbot/core/agent/agent.hpp>
#include <turbot/core/provider/provider.hpp>

using namespace turbot::core;

TEST_CASE("E2E-01: Simple Q&A", "[e2e]") {
    // 1. 创建会话
    auto session = session::Session::create({
        .project_id = "test",
        .slug = "e2e-test",
        .directory = "/tmp/test",
        .title = "E2E Test"
    });
    REQUIRE(session.has_value());

    // 2. 创建 Agent
    auto agent = agent::AgentRegistry::instance().get("build");
    REQUIRE(agent != nullptr);

    // 3. 创建 SessionLoop
    session::SessionLoop loop(*session, agent);

    // 4. 执行
    auto result = loop.run("What is 2+2?");

    // 5. 验证
    CHECK(result == session::LoopResult::Stop);
    CHECK_FALSE(loop.messages().empty());
}

TEST_CASE("E2E-02: Tool Call", "[e2e]") {
    auto session = session::Session::create({...});
    auto agent = agent::AgentRegistry::instance().get("build");
    session::SessionLoop loop(*session, agent);

    // Mock provider that returns tool call
    // ...

    auto result = loop.run("Read the file /tmp/test.txt");
    CHECK(result == session::LoopResult::Stop);
    // Verify tool was called
}

TEST_CASE("E2E-08: Doom Loop Detection", "[e2e]") {
    auto session = session::Session::create({...});
    auto agent = agent::AgentRegistry::instance().get("build");

    session::SessionLoopConfig config;
    config.doom_loop_threshold = 3;
    session::SessionLoop loop(*session, agent, config);

    // Mock provider that returns same tool call repeatedly
    // ...

    // Should detect doom loop after 3 identical calls
    auto result = loop.run("Keep doing the same thing");
    CHECK(loop.detected_doom_loop());
}
```

## 1. 概述

本计划是 Turbot-AI 项目的第二阶段实现，旨在建立完整的数据持久层。存储层是整个项目的基础设施，为所有上层业务提供数据存储和检索能力。

### 1.1 目标

- 实现数据库抽象层接口
- 实现 SQLite 存储后端
- 实现数据库迁移系统
- 支持事务处理
- 提供连接池功能

### 1.2 依赖关系

- **前置依赖**: 1.1 - 基础架构计划
- **后置依赖**: 核心数据模型、Agent 系统、会话系统

### 1.3 交付物

- ✅ 数据库抽象层接口 (`database.hpp`)
- ✅ SQLite 完整实现 (`sqlite_database.hpp/cpp`)
- ✅ 数据库迁移系统 (`migration.hpp/cpp`)
- ✅ 事务管理 (`transaction.hpp/cpp` + `TransactionGuard`)
- ⏳ 连接池实现（延后）
- ✅ 单元测试（**25 个测试用例**，全面覆盖）

## 4. 核心接口设计

### 4.1 数据库抽象层

> **实现说明**: 实际实现使用同步接口而非 `Task<T>` 异步接口。原因：
>
> 1. 当前阶段同步操作足够满足需求
> 2. SQLite 本身是同步 API，异步封装意义不大
> 3. 可在后续版本根据需要添加异步支持

**文件**: `libs/storage/include/turbot/storage/database.hpp`

```cpp
namespace turbot::storage {

struct QueryResult {
    std::vector<nlohmann::json> rows;
    int64_t affected_rows = 0;  // 添加默认值
};

struct DatabaseConfig {
    std::string path;
    bool read_only = false;
    int timeout = 30;  // 秒
    int cache_size = -2000;  // KB, 负数表示N*1024KB
    bool journal_wal = true;   // 新增：WAL模式开关
    bool foreign_keys = true;  // 新增：外键约束开关
};

class Database {
public:
    virtual ~Database() = default;

    // 执行查询（同步版本）
    virtual QueryResult execute(
        const std::string& sql,
        const std::vector<nlohmann::json>& params = {}
    ) = 0;

    // 执行查询并返回单行
    virtual std::optional<nlohmann::json> execute_one(
        const std::string& sql,
        const std::vector<nlohmann::json>& params = {}
    ) = 0;

    // 执行查询并返回标量值（模板方法）
    template<typename T>
    std::optional<T> execute_scalar(
        const std::string& sql,
        const std::vector<nlohmann::json>& params = {}
    );

    // 开始事务
    virtual std::shared_ptr<Transaction> begin_transaction() = 0;

    // 批量执行
    virtual QueryResult execute_batch(
        const std::string& sql,
        const std::vector<std::vector<nlohmann::json>>& params_list
    ) = 0;

    // 迁移
    virtual void migrate(
        const std::string& migration_name,
        const std::string& sql
    ) = 0;

    // 健康检查
    virtual bool health_check() = 0;

    // 获取配置
    virtual const DatabaseConfig& config() const = 0;

    // 关闭数据库
    virtual void close() = 0;

    // 新增：检查数据库是否打开
    virtual bool is_open() const = 0;
};

} // namespace turbot::storage
```

### 4.2 事务接口

**文件**: `libs/storage/database/transaction.hpp`

```cpp
namespace turbot::storage {

class Transaction {
public:
    virtual ~Transaction() = default;

    // 提交事务
    virtual Task<void> commit() = 0;

    // 回滚事务
    virtual Task<void> rollback() = 0;

    // 执行查询
    virtual Task<QueryResult> execute(
        const std::string& sql,
        const std::vector<nlohmann::json>& params = {}
    ) = 0;

    // 执行查询并返回单行
    virtual Task<std::optional<nlohmann::json>> execute_one(
        const std::string& sql,
        const std::vector<nlohmann::json>& params = {}
    ) = 0;

    // 事务是否活跃
    virtual bool is_active() const = 0;

protected:
    bool active_ = true;
};

// RAII事务守卫
class TransactionGuard {
public:
    TransactionGuard(std::shared_ptr<Transaction> tx)
        : tx_(std::move(tx)) {}

    ~TransactionGuard() {
        if (tx_ && tx_->is_active()) {
            // 自动回滚
            tx_->rollback();
        }
    }

    Task<void> commit() {
        if (tx_) {
            co_await tx_->commit();
            tx_.reset();
        }
    }

    Task<void> rollback() {
        if (tx_) {
            co_await tx_->rollback();
            tx_.reset();
        }
    }

    Transaction* operator->() { return tx_.get(); }

private:
    std::shared_ptr<Transaction> tx_;
};

} // namespace turbot::storage
```

**实现要点**:

```cpp
// 绑定参数
void bind_param(sqlite3_stmt* stmt, int index, const nlohmann::json& value) {
    if (value.is_null()) {
        sqlite3_bind_null(stmt, index);
    } else if (value.is_string()) {
        auto str = value.get<std::string>();
        sqlite3_bind_text(stmt, index, str.c_str(), static_cast<int>(str.size()),
                          SQLITE_TRANSIENT);
    } else if (value.is_number_integer()) {
        sqlite3_bind_int64(stmt, index, value.get<int64_t>());
    } else if (value.is_number_float()) {
        sqlite3_bind_double(stmt, index, value.get<double>());
    } else if (value.is_boolean()) {
        sqlite3_bind_int(stmt, index, value.get<bool>() ? 1 : 0);
    } else {
        // 复杂类型转为JSON字符串
        auto json_str = value.dump();
        sqlite3_bind_text(stmt, index, json_str.c_str(),
                          static_cast<int>(json_str.size()), SQLITE_TRANSIENT);
    }
}

// 行转JSON
nlohmann::json row_to_json(sqlite3_stmt* stmt) {
    nlohmann::json row;
    int count = sqlite3_column_count(stmt);
    for (int i = 0; i < count; i++) {
        const char* name = sqlite3_column_name(stmt, i);
        switch (sqlite3_column_type(stmt, i)) {
            case SQLITE_TEXT:
                row[name] = reinterpret_cast<const char*>(
                    sqlite3_column_text(stmt, i));
                break;
            case SQLITE_INTEGER:
                row[name] = sqlite3_column_int64(stmt, i);
                break;
            case SQLITE_FLOAT:
                row[name] = sqlite3_column_double(stmt, i);
                break;
            case SQLITE_BLOB: {
                int size = sqlite3_column_bytes(stmt, i);
                const void* blob = sqlite3_column_blob(stmt, i);
                row[name] = nlohmann::json::binary(
                    static_cast<const uint8_t*>(blob), size);
                break;
            }
            case SQLITE_NULL:
                row[name] = nullptr;
                break;
        }
    }
    return row;
}
```

## 5. 数据库优化

### 5.1 性能优化

**PRAGMA 设置**:

```cpp
void setup_performance(sqlite3* db) {
    // WAL模式（更好的并发性）
    execute("PRAGMA journal_mode=WAL;");

    // 同步级别（NORMAL平衡性能和安全）
    execute("PRAGMA synchronous=NORMAL;");

    // 缓存大小
    execute("PRAGMA cache_size=-2000;");  // 2GB

    // 临时存储在内存
    execute("PRAGMA temp_store=MEMORY;");

    // 内存映射I/O
    execute("PRAGMA mmap_size=30000000000;");  // 30GB

    // 外键约束
    execute("PRAGMA foreign_keys=ON;");

    // 优化器设置
    execute("PRAGMA optimize;");
}
```

```cpp
TEST_CASE("Transaction", "[storage][transaction]") {
    DatabaseConfig config;
    config.path = ":memory:";

    auto db = std::make_shared<SQLiteDatabase>(config);

    co_await db->execute(R"(
        CREATE TABLE test (
            id INTEGER PRIMARY KEY,
            value INTEGER
        )
    )");

    SECTION("commit") {
        auto tx = co_await db->begin_transaction();
        co_await tx->execute("INSERT INTO test (value) VALUES (1)");
        co_await tx->commit();

        auto result = co_await db->execute_one("SELECT COUNT(*) as count FROM test");
        REQUIRE((*result)["count"] == 1);
    }

    SECTION("rollback") {
        {
            auto tx = co_await db->begin_transaction();
            co_await tx->execute("INSERT INTO test (value) VALUES (1)");
            // 自动回滚
        }

        auto result = co_await db->execute_one("SELECT COUNT(*) as count FROM test");
        REQUIRE((*result)["count"] == 0);
    }
}
```

```cpp
{
    TransactionGuard tx(co_await db->begin_transaction());
```

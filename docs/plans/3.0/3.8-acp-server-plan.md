# 3.8 ACP JSON-RPC Server

> **所属版本**: v3.0 - ACP 子计划 1/3
> **创建时间**: 2026-03-14
> **依赖**: 无（ACP 链独立，可与 MCP/LSP 并行开发）
> **后续计划**: [3.9-acp-agent-plan.md](./3.9-acp-agent-plan.md)
> **估时**: 1.5 天
> **测试类型**: 单元测试（覆盖率 ≥ 80%）

---

## 目标

基于 JSON-RPC 2.0 over stdin/stdout 实现 ACP Server dispatcher，对齐 OpenCode `acp/server.ts`（使用官方 `@agentclientprotocol/sdk`；Turbot 手工实现协议层）。关键：协议分发表完整（11种方法）；错误码规范（-32601/-32602/authRequired）；ACPAgent 接口定义，为 3.9 提供 stub 基础。

### 步骤 1：定义 ACP 公共类型（acp.hpp）

**完整类型定义**：

```cpp
namespace turbot::core::acp {

struct ModelOption { std::string model_id; std::string name; };
struct ModeOption  {
    std::string id;
    std::string name;
    std::optional<std::string> description;
};

struct AgentCapabilities {
    // 对齐 OpenCode agentCapabilities 字段名（camelCase 嵌套结构）
    bool load_session = true;             // loadSession
    struct McpCaps {
        bool http = true;                 // mcpCapabilities.http
        bool sse  = true;                 // mcpCapabilities.sse
    } mcp_capabilities;
    struct PromptCaps {
        bool embedded_context = true;     // promptCapabilities.embeddedContext
        bool image            = true;     // promptCapabilities.image
    } prompt_capabilities;
    struct SessionCaps {
        bool fork   = true;               // sessionCapabilities.fork
        bool list   = true;               // sessionCapabilities.list
        bool resume = true;               // sessionCapabilities.resume
    } session_capabilities;
};

struct AuthMethod {
    std::string id;
    std::string name;
    std::string description;
    nlohmann::json meta = nlohmann::json::object();  // terminal-auth 能力元数据
};

struct AgentInfo { std::string name; std::string version; };

struct InitializeRequest {
    int protocol_version = 1;
    std::optional<std::string> authentication;
    nlohmann::json client_capabilities = nlohmann::json::object();
};

struct InitializeResponse {
    int protocol_version = 1;
    AgentCapabilities agent_capabilities;
    std::vector<AuthMethod> auth_methods;
    AgentInfo agent_info;
};

struct SessionInfo {
    std::string session_id;
    std::string cwd;
    std::optional<std::string> model_id;
    std::optional<std::string> mode;
    std::vector<nlohmann::json> mcp_servers;
    std::optional<std::string> title;
    std::optional<std::string> updated_at;
};

struct NewSessionRequest {
    std::string cwd;
    std::vector<nlohmann::json> mcp_servers;
    std::optional<std::string> model_id;
};

struct LoadSessionRequest {
    std::string session_id;
    std::string cwd;
    std::vector<nlohmann::json> mcp_servers;
    std::optional<std::string> model_id;
};

struct ResumeSessionRequest {
    std::string session_id;
    std::string cwd;
    std::vector<nlohmann::json> mcp_servers;
};

struct ForkSessionRequest  {
    std::string session_id;
    std::string cwd;
    std::vector<nlohmann::json> mcp_servers;
};
struct ForkSessionResponse { SessionInfo session; };

struct TextContent     { std::string type = "text"; std::string text; };
struct ResourceContent {
    std::string type = "resource";
    std::string uri;
    std::optional<std::string> mime_type;
};

struct PromptRequest {
    std::string session_id;
    std::vector<nlohmann::json> prompt;  // TextContent | ResourceContent | ImageContent | ResourceLinkContent
    std::optional<std::string> mode;
    std::optional<std::string> model;
};

struct SetSessionModeRequest  { std::string session_id; std::string mode_id; };
struct SetSessionModeResponse { std::string mode; };
struct SetSessionModelRequest { std::string session_id; std::string model_id; };
struct CancelNotification     { std::string session_id; };

struct ListSessionsRequest {
    std::optional<std::string> cwd;
    std::optional<std::string> cursor;  // Unix timestamp（秒），分页游标
};

enum class StopReason { EndTurn, ToolUse, StopSequence, Error, Cancelled };

struct Usage {
    int total_tokens = 0;
    int input_tokens = 0;
    int output_tokens = 0;
    std::optional<int> thought_tokens;
    std::optional<int> cached_read_tokens;
    std::optional<int> cached_write_tokens;
};

} // namespace turbot::core::acp
```

**JSON 序列化/反序列化**（使用 nlohmann::json）：

- 所有 Request/Response 类型实现 `to_json()`/`from_json()`（或使用 `NLOHMANN_DEFINE_TYPE_NON_INTRUSIVE`）
- camelCase 字段名（对齐 ACP 协议：`sessionId`, `mcpServers`, `modelId` 等）

**验收**：所有类型编译通过，JSON 序列化/反序列化往返正确

### 步骤 2：定义 ACPAgent 接口（在 server.hpp 中前向声明，完整实现见 3.9）

```cpp
// server.hpp（前向声明 ACPAgent 接口）
namespace turbot::core::acp {

class ACPAgent {
public:
    virtual ~ACPAgent() = default;

    virtual InitializeResponse initialize(const InitializeRequest& req) = 0;
    virtual nlohmann::json     new_session(const NewSessionRequest& req) = 0;
    virtual nlohmann::json     load_session(const LoadSessionRequest& req) = 0;
    virtual nlohmann::json     resume_session(const ResumeSessionRequest& req) = 0;
    virtual nlohmann::json     list_sessions(const ListSessionsRequest& req) = 0;
    virtual ForkSessionResponse fork_session(const ForkSessionRequest& req) = 0;

    // prompt：流式执行，on_update 每次有更新时被调用（对齐 connection.sessionUpdate）
    virtual nlohmann::json prompt(
        const PromptRequest& req,
        std::function<void(const nlohmann::json& update_payload)> on_update
    ) = 0;

    virtual void                   cancel(const CancelNotification& notif) = 0;
    virtual SetSessionModeResponse set_mode(const SetSessionModeRequest& req) = 0;
    virtual nlohmann::json         set_model(const SetSessionModelRequest& req) = 0;
    virtual void                   authenticate(const nlohmann::json& req) = 0;
};

} // namespace turbot::core::acp
```

### 步骤 3：实现 ACPServer dispatcher（server.cpp）

**协议分发表**（完整 11 种方法）：

| JSON-RPC Method  | 处理器                       | 说明                                                                                                |
| ---------------- | ---------------------------- | --------------------------------------------------------------------------------------------------- |
| `initialize`     | `ACPAgent::initialize()`     | 协议握手，返回 InitializeResponse                                                                   |
| `session/new`    | `ACPAgent::new_session()`    | 创建新会话，返回模型/模式列表                                                                       |
| `session/load`   | `ACPAgent::load_session()`   | 加载已有会话（含历史回放）                                                                          |
| `session/resume` | `ACPAgent::resume_session()` | 轻量恢复（不回放历史，仅同步状态）                                                                  |
| `session/prompt` | `ACPAgent::prompt()`         | 执行 prompt，流式推送 `session/update`                                                              |
| `session/fork`   | `ACPAgent::fork_session()`   | Fork 会话（含历史回放）                                                                             |
| `session/mode`   | `ACPAgent::set_mode()`       | 切换模式（modeId）                                                                                  |
| `session/model`  | `ACPAgent::set_model()`      | 切换模型（modelId，含 variant 解析）                                                                |
| `session/list`   | `ACPAgent::list_sessions()`  | 列出会话（分页，支持 cursor）                                                                       |
| `authenticate`   | `ACPAgent::authenticate()`   | 认证请求（无 Provider 配置时直接 throw `authRequired`；当前设计不支持运行时凭据刷新，如需单独设计） |
| `cancel`         | `ACPAgent::cancel()`         | 取消当前 prompt（通知，无需响应）                                                                   |

**错误码**：

- 未知方法：`-32601 Method not found`
- 参数无效/缺失：`-32602 Invalid params`
- 内部错误：`-32603 Internal error`
- 认证要求：ACP authRequired 错误（对齐 ACP 协议）

**ACPServer 实现**：

```cpp
class ACPServer {
public:
    ACPServer() = delete;

    // 启动服务器（阻塞直到 stdin EOF 或 stop() 被调用）
    static void start(
        std::function<std::unique_ptr<ACPAgent>()> agent_factory,
        const std::string& cwd = "."
    );

    // 停止服务器（线程安全，可从 SIGTERM/SIGINT 处理器调用）
    static void stop();

private:
    static void dispatch(
        const nlohmann::json& request,
        std::unique_ptr<ACPAgent>& agent,
        const std::function<void(const nlohmann::json&)>& write_fn
    );
    static nlohmann::json make_error(int64_t id, int code, const std::string& message);
    static nlohmann::json make_result(int64_t id, const nlohmann::json& result);
    static void write_response(const nlohmann::json& response);
};
```

**主循环逻辑**（stdin 读取）：

```
loop:
  readline from stdin → parse JSON
  if parse error → write -32700 Parse error
  if not object → write -32600 Invalid Request
  method = request["method"]
  id = request.get("id")  // 可选
  dispatch(request, agent, write_fn)
  → 找到 method → 调用对应处理器 → write result
  → 未找到 method → write -32601
  → 处理器抛出异常 → write -32603
EOF → break
```

**`session/update` 通知推送**（通知，无 id，实时写入 stdout）：

```cpp
// 在 session/prompt 处理期间，on_update 被调用时：
auto write_update = [&](const nlohmann::json& payload) {
    nlohmann::json notif = {
        {"jsonrpc", "2.0"},
        {"method", "session/update"},
        {"params", payload}
    };
    write_response(notif);  // 写入 stdout（无 id，为通知）
};
agent->prompt(req, write_update);
```

**`cancel` 特殊处理**（通知，无 id）：

```cpp
// cancel 为通知（无 id）
// 直接调用 agent->cancel()，不写响应
if (!request.contains("id")) {
    agent->cancel(parse_cancel(request["params"]));
    return;  // 通知不需要响应
}
```

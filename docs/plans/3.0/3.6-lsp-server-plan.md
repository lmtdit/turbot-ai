## 实施步骤

### 步骤 1：LSPServerInfo 描述符（server.hpp）

```cpp
struct LSPServerInfo {
    std::string id;
    std::vector<std::string> extensions;  // 文件扩展名（含点，如 ".cpp"），空=全局
    bool global = false;

    // 根目录检测（对齐 OpenCode NearestRoot）：
    // - 从 file 目录向上查找特征文件/目录
    // - 支持 include_patterns 和 exclude_patterns
    // - 返回 nullopt 表示不适用
    std::function<std::optional<std::string>(const std::string& file)> root;

    // 启动语言服务器（对齐 OpenCode server.spawn）：
    // - 返回 nullopt 表示服务器未安装（不抛异常）
    // - 返回 ServerHandle（已 fork 的子进程）
    std::function<std::optional<ServerHandle>(const std::string& root_dir)> spawn;
};

// NearestRoot 辅助函数（对齐 OpenCode NearestRoot 函数）
// 从 start_dir 向上遍历，查找包含任意 include_patterns 的目录
// 可选 exclude_patterns（如有则该目录内不计入）
std::optional<std::string> nearest_root(
    const std::string& start_dir,
    const std::vector<std::string>& include_patterns,
    const std::vector<std::string>& exclude_patterns = {}
);
```

### 步骤 2：LSPManager 单例（manager.hpp / manager.cpp）

```cpp
class LSPManager {
public:
    static LSPManager& instance();
    LSPManager(const LSPManager&) = delete;
    LSPManager& operator=(const LSPManager&) = delete;

    // 初始化：注册所有内置服务器，从 Config 读取用户定义服务器
    // Config "lsp" == false → 不启用任何服务器（对齐 OpenCode cfg.lsp === false）
    void initialize();

    void register_server(LSPServerInfo server);
    void disable_server(const std::string& id);

    // 按文件获取（或懒启动）对应客户端列表
    std::future<std::vector<LSPClient*>> get_clients(const std::string& file);

    // 检查指定文件是否有匹配的 LSP 服务器（不启动，对齐 OpenCode hasClients）
    bool has_clients(const std::string& file);

    // 通知文件被打开（激活 LSP，发送 didOpen；wait_for_diagnostics 可选）
    void touch_file(const std::string& file, bool wait_for_diagnostics = false);

    std::unordered_map<std::string, std::vector<Diagnostic>> diagnostics();

    // 广播方法（转发到所有匹配客户端）
    std::future<std::optional<Hover>>             hover(const std::string& file, Position pos);
    std::future<std::vector<Location>>            definition(const std::string& file, Position pos);
    std::future<std::vector<Location>>            references(const std::string& file, Position pos);
    std::future<std::vector<Symbol>>              workspace_symbol(const std::string& query);
    std::future<std::vector<nlohmann::json>>      document_symbol(const std::string& uri);

    // 连接状态列表（对齐 OpenCode LSP.status()）
    [[nodiscard]] std::vector<nlohmann::json> status() const;

    void shutdown();

private:
    LSPManager() = default;

    mutable std::shared_mutex mutex_;
    std::unordered_map<std::string, LSPServerInfo> servers_;
    std::vector<std::unique_ptr<LSPClient>> clients_;
    std::set<std::string> broken_;        // "root+serverID" 键，标记失败服务器
    std::unordered_map<std::string, std::future<LSPClient*>> spawning_;  // 启动中
};
```

**关键实现细节**：

#### `get_clients(file)` 懒启动逻辑：

```
对每个 server in servers_：
  1. 检查扩展名匹配（file 的后缀是否在 server.extensions 中）
  2. 调用 server.root(file) 获取 project root
  3. 构造 key = root + "+" + server.id
  4. broken_.count(key) > 0 → 跳过
  5. spawning_.count(key) > 0 → 等待已有的 future
  6. 否则：调用 server.spawn(root)
     - 返回 nullopt → broken_.insert(key)，跳过
     - 返回 handle → LSPClient::create(server.id, handle, root)
       - 成功 → clients_.push_back()，发布 EventBus "lsp.updated"
       - 失败（nullptr）→ broken_.insert(key)
```

#### `has_clients(file)` 仅检查（对齐 OpenCode `hasClients`）：

```
对每个 server in servers_：
  检查扩展名匹配 && server.root(file) 有值 && not in broken_
  → 返回 true（不启动服务器）
```

#### `touch_file(file, wait_for_diagnostics)` 激活流程：

```
clients = get_clients(file).get()
for each client:
  client->notify_open(file)
  if wait_for_diagnostics:
    client->wait_for_diagnostics(file).get()
```

### 步骤 3：内置服务器实现

#### Clangd（C/C++ LSP）

```cpp
// builtin/clangd_server.cpp
LSPServerInfo make_clangd_server() {
    return {
        .id = "clangd",
        .extensions = {".c", ".cpp", ".h", ".hpp", ".cc", ".cxx"},
        .root = [](const std::string& file) -> std::optional<std::string> {
            // 优先查找 compile_commands.json，其次 CMakeLists.txt
            return nearest_root(std::filesystem::path(file).parent_path().string(),
                                {"compile_commands.json", "CMakeLists.txt"});
        },
        .spawn = [](const std::string& root_dir) -> std::optional<ServerHandle> {
            // 检查 clangd 是否可用（which clangd）
            if (!command_exists("clangd")) return std::nullopt;
            // fork + execvp: clangd --compile-commands-dir={root_dir}
            return spawn_process({"clangd", "--compile-commands-dir=" + root_dir}, root_dir);
        }
    };
}
```

#### Pyright（Python LSP）

```cpp
LSPServerInfo make_pyright_server() {
    return {
        .id = "pyright",
        .extensions = {".py"},
        .root = [](const std::string& file) -> std::optional<std::string> {
            return nearest_root(std::filesystem::path(file).parent_path().string(),
                                {"pyproject.toml", "setup.py", "requirements.txt"});
        },
        .spawn = [](const std::string& root_dir) -> std::optional<ServerHandle> {
            // 可被 OPENCODE_EXPERIMENTAL_LSP_TY 环境变量替换为 ty
            bool use_ty = std::getenv("OPENCODE_EXPERIMENTAL_LSP_TY") != nullptr;
            std::string cmd = use_ty ? "ty" : "pyright-langserver";
            if (!command_exists(cmd)) return std::nullopt;
            return spawn_process({cmd, "--stdio"}, root_dir);
        }
    };
}
```

#### Gopls（Go LSP）

```cpp
LSPServerInfo make_gopls_server() {
    return {
        .id = "gopls",
        .extensions = {".go"},
        .root = [](const std::string& file) -> std::optional<std::string> {
            // 优先 go.work，其次 go.mod
            auto r = nearest_root(std::filesystem::path(file).parent_path().string(), {"go.work"});
            if (!r) r = nearest_root(std::filesystem::path(file).parent_path().string(), {"go.mod"});
            return r;
        },
        .spawn = [](const std::string& root_dir) -> std::optional<ServerHandle> {
            if (!command_exists("gopls")) {
                // 可尝试自动安装到 ~/.turbot/bin（对齐 OpenCode Gopls 服务器实现）
                // 简化版：尝试 go install，如无 go 环境则跳过
                // 实际可通过 InstallIfMissing 策略
                return std::nullopt;
            }
            return spawn_process({"gopls"}, root_dir);
        }
    };
}
```

#### 服务器未安装处理（所有服务器通用）：

- `spawn()` 返回 `nullopt`
- Manager 将 `root+serverID` 加入 `broken_` 集合
- 后续跳过，不抛异常（对齐 OpenCode 行为）

### 步骤 4：用户自定义服务器支持

**Config 格式**（`"lsp"` 键下）：

```json
{
  "lsp": {
    "rust-analyzer": {
      "command": ["rust-analyzer"],
      "extensions": [".rs"],
      "disabled": false
    },
    "my-server": {
      "command": ["my-lsp", "--stdio"],
      "extensions": [".xyz"],
      "initialization": { "setting": "value" },
      "env": { "MY_VAR": "value" }
    }
  }
}
```

**解析逻辑**（`manager.cpp` 中 `initialize()`）：

```cpp
void LSPManager::initialize() {
    // 检查全局禁用
    auto lsp_cfg = Config::instance().get<nlohmann::json>("lsp");
    if (lsp_cfg.is_boolean() && lsp_cfg.get<bool>() == false) return;

    // 注册内置服务器
    register_server(make_clangd_server());
    register_server(make_pyright_server());
    register_server(make_gopls_server());

    // 解析用户自定义服务器
    if (lsp_cfg.is_object()) {
        for (auto& [id, cfg] : lsp_cfg.items()) {
            if (cfg.value("disabled", false)) continue;
            register_server(make_custom_server(id, cfg));
        }
    }
}
```

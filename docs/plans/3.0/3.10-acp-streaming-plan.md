## 实施步骤

### 步骤 1：完善 session/update 8 种类型（在 agent.cpp 中验证完整性）

**完整类型清单**（对齐 OpenCode agent.ts 实际实现，共 8 种）：

#### 类型 1：`agent_message_chunk`（AI 文本流）

```json
{
  "sessionUpdate": "agent_message_chunk",
  "content": { "type": "text", "text": "...chunk..." }
}
```

**触发**：`session.message.part.delta` 事件，part.type=text，ignored != true

#### 类型 2：`user_message_chunk`（历史回放用户消息）

```json
{
  "sessionUpdate": "user_message_chunk",
  "content": {
    "type": "text",
    "text": "...",
    "annotations": { "audience": ["user"] }
  }
}
```

**触发**：`process_message()` 中 role=user 的 text part

#### 类型 3：`agent_thought_chunk`（推理流，reasoning）

```json
{
  "sessionUpdate": "agent_thought_chunk",
  "content": { "type": "text", "text": "...reasoning delta..." }
}
```

**触发**：`session.message.part.delta` 事件，part.type=reasoning field=text

#### 类型 4：`tool_call`（工具初始 pending，每个 callID 仅发一次）

```json
{
  "sessionUpdate": "tool_call",
  "toolCallId": "...",
  "title": "bash",
  "kind": "execute",
  "status": "pending",
  "locations": [],
  "rawInput": {}
}
```

**触发**：`session.tool.start` 事件（每个 callID 仅第一次）

#### 类型 5：`tool_call_update`（工具状态更新，3种 status：in_progress/completed/failed）

```json
{
  "sessionUpdate": "tool_call_update",
  "toolCallId": "...",
  "status": "in_progress" | "completed" | "failed",
  "kind": "read" | "write" | "edit" | "execute" | "fetch" | "search" | "other",
  "title": "...",
  "locations": [{"path": "/abs/path"}],
  "rawInput": {...},
  "rawOutput": { "output": "...", "metadata": {...} },
  "content": [
    { "type": "content", "content": { "type": "text", "text": "..." } },
    { "type": "diff", "path": "...", "oldText": "...", "newText": "..." }
  ]
}
```

**触发**：`session.message.part.updated` 事件（注：edit 工具时额外附加 diff block）

#### 类型 6：`usage_update`（用量统计，prompt 完成后异步发送）

```json
{
  "sessionUpdate": "usage_update",
  "used": 1234,
  "size": 200000,
  "cost": { "amount": 0.01, "currency": "USD" }
}
```

**`used` 计算**：input_tokens + cached_read_tokens（对齐 OpenCode 语义）
**`size`**：模型上下文窗口大小（从 Provider 获取）

#### 类型 7：`plan`（todowrite 工具完成时额外发送）

```json
{
  "sessionUpdate": "plan",
  "entries": [
    { "priority": "medium", "status": "in_progress" | "completed" | "pending", "content": "..." }
  ]
}
```

**触发**：工具名 == "todowrite" 且 status == "completed"，解析工具输出中的 todo 条目

#### 类型 8：`available_commands_update`（session 创建/加载后异步推送）

```json
{
  "sessionUpdate": "available_commands_update",
  "availableCommands": [
    { "name": "compact", "description": "compact the session" },
    ...
  ]
}
```

**触发**：session 创建/加载后，setTimeout 0 等价的异步推送（对齐 OpenCode）

**ToolKind 映射验证**（确保在 agent.cpp 中的 `to_tool_kind()` 实现完整）：

| 工具名                       | Kind      |
| ---------------------------- | --------- |
| `bash`                       | `execute` |
| `webfetch`                   | `fetch`   |
| `edit`, `patch`, `write`     | `edit`    |
| `grep`, `glob`, `context7_*` | `search`  |
| `list`, `read`               | `read`    |
| 其他（MCP 工具等）           | `other`   |

**验收**：`session/prompt` 执行时能收到类型 1、4、5、6；历史回放时收到类型 2、3（若有 reasoning）；todowrite 工具触发类型 7；session/new 后收到类型 8

### 步骤 2：实现 `turbot acp` CLI 子命令

**文件**：`apps/turbot-cli/src/cmd/acp_cmd.cpp`

**命令行接口**：

```
turbot acp [--cwd <dir>]
```

**实现**：

```cpp
// acp_cmd.cpp
#include <turbot/core/acp/server.hpp>
#include <turbot/core/acp/agent.hpp>
#include <csignal>

void register_acp_command(CLI::App& app) {
    auto* acp = app.add_subcommand("acp", "Start ACP server for IDE integration");
    std::string cwd = ".";
    acp->add_option("--cwd", cwd, "Working directory");

    acp->callback([&cwd]() {
        // SIGTERM/SIGINT → ACPServer::stop()（优雅关闭）
        std::signal(SIGTERM, [](int) { ACPServer::stop(); });
        std::signal(SIGINT,  [](int) { ACPServer::stop(); });

        // 启动 ACP Server
        // TURBOT_ENABLE_QUESTION_TOOL=1 → 启用 QuestionTool
        bool enable_question = std::getenv("TURBOT_ENABLE_QUESTION_TOOL") != nullptr;
        // （QuestionTool 允许 AI 向用户提问，默认禁用）

        ACPServer::start(
            [&cwd, enable_question]() {
                return std::make_unique<TurbotACPAgent>(cwd, enable_question);
            },
            cwd
        );
    });
}
```

**优雅关闭**：

- `SIGTERM/SIGINT` 触发 `ACPServer::stop()`
- `stop()` 设置停止标志，主循环在当前请求（如 prompt）处理完成后退出
- 若 prompt 正在执行，调用 `Session::abort()` 取消

**验收**：

- `turbot acp` 启动后响应 `initialize` 请求
- `SIGTERM` 触发优雅关闭

// tests/e2e/acp/test_acp_zed_integration.cpp

// 测试 1：完整 ACP 会话流程
TEST(ACPZedIntegration, FullSessionFlow) {
    // 通过 pipe 连接 ACPServer（模拟 Zed 调用 turbot acp）
    auto [server_pid, stdin_fd, stdout_fd] = spawn_turbot_acp(".");

    // initialize
    send_jsonrpc(stdin_fd, {{"id",1},{"method","initialize"},{"params",{{"protocolVersion",1}}}});
    auto init_resp = read_jsonrpc(stdout_fd);
    EXPECT_TRUE(init_resp["result"].contains("agentCapabilities"));

    // session/new
    send_jsonrpc(stdin_fd, {{"id",2},{"method","session/new"},{"params",{{"cwd","."},{...}}}});
    auto new_resp = read_jsonrpc(stdout_fd);
    std::string session_id = new_resp["result"]["sessionId"];

    // session/prompt（等待 session/update 通知）
    send_jsonrpc(stdin_fd, {{"id",3},{"method","session/prompt"},
        {"params",{{"sessionId",session_id},{"prompt",[{{"type","text"},{"text","Hello"}}]}}}});

    std::vector<nlohmann::json> updates;
    nlohmann::json final_resp;
    while (true) {
        auto msg = read_jsonrpc(stdout_fd);
        if (msg.contains("id") && msg["id"] == 3) { final_resp = msg; break; }
        if (msg.value("method","") == "session/update") updates.push_back(msg);
    }
    EXPECT_FALSE(updates.empty());

    // SIGTERM 优雅关闭
    kill(server_pid, SIGTERM);
    EXPECT_EQ(waitpid(server_pid, nullptr, 0), server_pid);
}

## 验收标准

1. `turbot acp` 启动后响应 `initialize` 请求，返回含 `agentCapabilities` 的 `InitializeResponse`
2. `session/prompt` 执行期间持续推送 `session/update` 通知（`agent_message_chunk`）
3. 工具执行时推送 `tool_call` (pending) → `tool_call_update` (in_progress/completed/failed)
4. `todowrite` 工具完成时推送 `plan` 通知
5. `session/new`/`session/load` 后异步推送 `available_commands_update`
6. SIGTERM 触发优雅关闭（当前 prompt 处理完成后退出）
7. E2E 测试通过（模拟 Zed IDE 完整会话流程）

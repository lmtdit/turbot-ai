## 目标

实现 `TurbotACPAgent`（桥接 ACP 协议到 Turbot Session 系统）和 `ACPSessionManager`（维护 ACP→内部 Session 状态映射）。关键功能：完整历史回放（弥补 OpenCode 缺陷6）；权限系统集成（`permission.asked` 事件）；流式事件驱动（弥补 OpenCode 缺陷1/2）；listSessions 分页（limit=100，cursor=Unix timestamp）。

### 步骤 2：实现 TurbotACPAgent（agent.cpp）

#### `initialize()`（对齐 OpenCode `Agent.initialize`）

```
- 检查 req.client_capabilities["_meta"]["terminal-auth"] 是否为 true（能力协商）
- 返回 InitializeResponse：
    agentCapabilities：{loadSession, mcpCapabilities, sessionCapabilities 等全部 true}
    authMethods：[{"id": "turbot-login", "name": "Turbot Login", ...}]
    agentInfo：{name: "Turbot", version: TURBOT_VERSION}
```

#### `new_session()`（对齐 OpenCode `Agent.newSession`）

```
1. 调用 Session::create({directory: req.cwd, ...})，创建 Turbot Session
2. 动态加载 MCP 服务器（MCPManager::add()，仅 req.mcp_servers 指定的）
3. 解析可用 modes（Turbot Agent 列表）
4. 解析可用 models（Provider 列表，含 variants）
   - 检查 model._meta.opencode.availableVariants（对齐 OpenCode model variants）
5. 通过 on_update 异步推送 available_commands_update（对齐 OpenCode setTimeout 0 推送）
6. 返回 SessionInfo + models + modes
```

#### `load_session()`（完整历史回放，弥补 OpenCode 缺陷6）

```
1. 调用 Session::get(session_id) 验证 Session 存在（不存在 → -32602 error）
2. 调用 Session::messages() 获取历史消息列表
3. 调用 process_message(msg, on_update) 逐条回放到 ACP 客户端
4. 从历史消息推断当前 model/mode（对齐 OpenCode loadSession 实现）
5. 推送 usage_update（汇总历史用量）
6. 推送 available_commands_update（异步，与 new_session 同逻辑）
7. 返回 SessionInfo
```

#### `resume_session()`（轻量恢复，对齐 OpenCode `unstable_resumeSession`）

```
1. 调用 Session::get(session_id) 验证存在
2. 不回放历史，仅同步状态
3. 推送 usage_update（最新用量）
4. 返回 SessionInfo
```

#### `list_sessions()`（对齐 OpenCode `unstable_listSessions`，分页）

```
1. 调用 Session::list({roots: true}) 获取所有 Session
2. 按 time.updated 降序排序
3. 分页：limit = 100
4. cursor 为 Unix timestamp（秒）：过滤 time.updated < cursor
5. 返回 {sessions: [...], nextCursor: last_session.time.updated | null}
```

#### `fork_session()`（对齐 OpenCode `unstable_forkSession`）

```
1. 调用 Session::fork({parent_id: req.session_id})
2. 调用 process_message() 历史回放（与 load_session 相同）
3. 推送 usage_update
4. 返回 ForkSessionResponse{session: SessionInfo}
```

#### `prompt()`（弥补 OpenCode 缺陷1/2 - Streaming/Tool Reporting）

```
1. 检查 / 命令前缀：
   - "/compact" → session.summarize()，通知 agent_message_chunk
   - 其他 / 命令 → CommandRegistry 查找执行
2. 设置 model/mode（若 req.model 或 req.mode 有值）
3. 订阅 EventBus session 事件，通过 on_update 推送流式更新：
   - "session.message.part.delta" → agent_message_chunk（text）或 agent_thought_chunk（reasoning）
   - "session.tool.start"         → tool_call（pending，每个 callID 仅一次）
   - "session.message.part.updated" → tool_call_update（in_progress/completed/failed）
4. 调用 Session::prompt(session_id, messages)（阻塞直到完成）
5. 完成后推送 usage_update（含 total/input/output/thought/cached 字段）
6. 返回 {stopReason: "end_turn", sessionId: ..., usage: ...}
```

#### `cancel()`（对齐 OpenCode `sdk.session.abort()`）

```
调用 Session::abort(notif.session_id)
```

#### `set_mode()`（弥补 OpenCode 缺陷3 - Session Modes）

```
1. 验证 mode 在可用 Agents 列表中存在（不存在 → -32602 error）
2. ACPSessionManager::set_mode(session_id, mode_id)
3. 返回 SetSessionModeResponse{mode: mode_id}
```

#### `set_model()`

```
1. 解析 model_id（格式："{providerID}/{modelID}"，含可选 variant 后缀）
2. ACPSessionManager::set_model(session_id, provider_id, model_id)
3. 若有 variant，调用 set_variant()
4. 返回 {model: ..., provider: ...}
```

#### `authenticate()`（当前抛出 authRequired 错误）

```
throw ACP authRequired error
（对齐 OpenCode agent.ts authenticate：当前实现抛出异常）
```

### 步骤 3：process_message() 历史回放（核心私有方法）

**对齐 OpenCode `processMessage` 私有方法**（acp/agent.ts 中的 `processMessage`）：

```cpp
// process_message：将单条 Turbot Session 历史消息转换为 ACP session/update 通知序列
void TurbotACPAgent::process_message(
    const turbot::core::session::Message& msg,
    const std::function<void(const nlohmann::json&)>& on_update
) {
    for (const auto& part : msg.parts()) {
        if (part.type == "text") {
            if (msg.role == "user") {
                // user_message_chunk（历史回放用户消息）
                on_update({{"sessionUpdate", "user_message_chunk"},
                           {"content", {{"type", "text"}, {"text", part.text},
                                        {"annotations", {{"audience", {"user"}}}}}}});
            } else {
                // agent_message_chunk
                on_update({{"sessionUpdate", "agent_message_chunk"},
                           {"content", {{"type", "text"}, {"text", part.text}}}});
            }
        } else if (part.type == "reasoning") {
            // agent_thought_chunk（推理流）
            on_update({{"sessionUpdate", "agent_thought_chunk"},
                       {"content", {{"type", "text"}, {"text", part.text}}}});
        } else if (part.type == "tool") {
            // tool_call（pending）+ tool_call_update（完成/失败）
            auto kind = to_tool_kind(part.tool_name);
            on_update({{"sessionUpdate", "tool_call"},
                       {"toolCallId", part.call_id}, {"title", part.tool_name},
                       {"kind", kind}, {"status", "pending"}, {"locations", nlohmann::json::array()},
                       {"rawInput", part.args}});
            // 工具状态更新（根据 part.status 映射）
            std::string status = part.status == "completed" ? "completed"
                               : part.status == "error"     ? "failed"
                               : "in_progress";
            nlohmann::json update = {
                {"sessionUpdate", "tool_call_update"},
                {"toolCallId", part.call_id}, {"status", status},
                {"kind", kind}, {"title", part.tool_name},
                {"locations", build_locations(part)},
                {"rawInput", part.args}
            };
            if (status == "completed") {
                update["rawOutput"] = {{"output", part.output}};
                update["content"] = build_content(part);  // 含 diff block（edit 工具）
            }
            on_update(update);

            // todowrite 工具额外发送 plan 更新
            if (part.tool_name == "todowrite" && status == "completed") {
                on_update(build_plan_update(part.output));
            }
        } else if (part.type == "file") {
            // resource_link / image / resource（URL 类型判断）
            process_file_part(part, msg, on_update);
        }
    }
}
```

**`to_tool_kind()` 映射**（对齐 OpenCode `toToolKind` 函数）：

```cpp
std::string to_tool_kind(const std::string& tool_name) {
    if (tool_name == "bash") return "execute";
    if (tool_name == "webfetch") return "fetch";
    if (tool_name == "edit" || tool_name == "patch" || tool_name == "write") return "edit";
    if (tool_name == "grep" || tool_name == "glob") return "search";
    if (tool_name.starts_with("context7_")) return "search";
    if (tool_name == "list" || tool_name == "read") return "read";
    return "other";
}
```

**`process_file_part()` 类型判断**（对齐 OpenCode processMessage file part 处理）：

```cpp
void process_file_part(const Part& part, const Message& msg,
                        const std::function<void(const nlohmann::json&)>& on_update) {
    const auto& url = part.url;
    if (url.starts_with("file://")) {
        // resource_link
        on_update({{"sessionUpdate", "resource_link"}, {"url", url}});
    } else if (url.starts_with("data:")) {
        auto mime = extract_mime(url);
        if (mime.starts_with("image/")) {
            // image block
            on_update({{"sessionUpdate", "agent_message_chunk"},
                       {"content", {{"type", "image"}, {"url", url}, {"mimeType", mime}}}});
        } else {
            bool is_text = mime.starts_with("text/") || mime == "application/json";
            if (is_text) {
                // resource with text（解码 base64 data URL）
                on_update({{"sessionUpdate", "agent_message_chunk"},
                           {"content", {{"type", "resource"}, {"text", decode_data_url(url)}}}});
            } else {
                // resource with blob
                on_update({{"sessionUpdate", "agent_message_chunk"},
                           {"content", {{"type", "resource"}, {"blob", url}}}});
            }
        }
    }
}
```

### 步骤 4：权限系统集成（ACP permission 系统）

**对齐 OpenCode `permission.asked` 事件流程**：

```cpp
// 在 TurbotACPAgent::prompt() 执行期间，监听权限请求：
// 1. 订阅 EventBus "permission.asked" 事件
// 2. 收到事件时，通过 on_update 推送 requestPermission 到 ACP 客户端
// 3. ACP 客户端回复 → 触发 EventBus "permission.reply" 事件

// 权限请求通知（推送到 ACP 客户端）
struct PermissionRequest {
    std::string permission_id;
    std::string title;
    std::string description;
    std::string tool_name;
};

// 订阅示例（在 prompt() 期间注册）：
auto sub = EventBus::instance().subscribe<PermissionRequest>("permission.asked",
    [&on_update](const auto& event) {
        on_update({
            {"sessionUpdate", "request_permission"},
            {"permissionId", event.data.permission_id},
            {"title", event.data.title},
            {"description", event.data.description}
        });
    });
```

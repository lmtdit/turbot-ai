## 目标

实现 OAuth 2.0 + PKCE 完整认证流程，含 Token 持久化存储（`~/.turbot/mcp-auth.json`，权限 0600），对齐 OpenCode `mcp/auth.ts` + `mcp/oauth-provider.ts`。关键行为：`is_token_expired()` 三态返回；`authenticate()` 防竞争条件（先注册 callback 再开浏览器）；浏览器打开失败时发布 EventBus 事件。

## 实施步骤

### 步骤 1：实现 McpAuth（auth.hpp / auth.cpp）

**核心数据结构**：

```cpp
struct Tokens {
    std::string access_token;
    std::optional<std::string> refresh_token;
    std::optional<int64_t> expires_at;  // Unix 时间戳（秒）
    std::optional<std::string> scope;
};

struct ClientInfo {
    std::string client_id;
    std::optional<std::string> client_secret;
    std::optional<int64_t> client_id_issued_at;
    std::optional<int64_t> client_secret_expires_at;
};

struct AuthEntry {
    std::optional<Tokens>     tokens;
    std::optional<ClientInfo> client_info;
    std::optional<std::string> code_verifier;  // PKCE 验证码
    std::optional<std::string> oauth_state;    // CSRF state
    std::optional<std::string> server_url;     // URL 绑定校验
};
```

**关键 API**：

```cpp
class McpAuth {
public:
    static std::optional<AuthEntry> get(const std::string& mcp_name);

    // URL 绑定校验（对齐 OpenCode McpAuth.getForUrl）：
    // - server_url 与存储不匹配 → 返回 nullopt（凭据失效）
    // - 无 serverUrl 字段 → 返回 nullopt
    static std::optional<AuthEntry> get_for_url(
        const std::string& mcp_name,
        const std::string& server_url
    );

    static void set(const std::string& mcp_name, const AuthEntry& entry,
                    const std::optional<std::string>& server_url = {});
    static void remove(const std::string& mcp_name);

    static void update_tokens(const std::string& mcp_name, const Tokens& tokens,
                               const std::optional<std::string>& server_url = {});
    static void update_client_info(const std::string& mcp_name, const ClientInfo& info,
                                    const std::optional<std::string>& server_url = {});
    static void update_code_verifier(const std::string& mcp_name, const std::string& verifier);
    static void update_oauth_state(const std::string& mcp_name, const std::string& state);
    static void clear_oauth_state(const std::string& mcp_name);
    static void clear_code_verifier(const std::string& mcp_name);

    // 三态返回（对齐 OpenCode isTokenExpired 返回 boolean | null 语义）：
    // - nullopt：无 token 存储
    // - false：无 expiresAt 字段或 token 未过期
    // - true：token 已过期
    static std::optional<bool> is_token_expired(const std::string& mcp_name);

    static std::optional<std::string> get_oauth_state(const std::string& mcp_name);

    enum class AuthStatus { Authenticated, Expired, NotAuthenticated };
    static AuthStatus get_auth_status(const std::string& mcp_name);

private:
    static std::string auth_file_path();  // ~/.turbot/mcp-auth.json
    static nlohmann::json read_all();
    static void write_all(const nlohmann::json& data);  // 写入时 chmod 0600
};
```

**`is_token_expired()` 实现逻辑**（严格对齐 OpenCode `auth.ts` `isTokenExpired`）：

```
entry = get(mcp_name)
if !entry || !entry.tokens → return nullopt（null 无 token）
if !entry.tokens.expires_at → return false（无过期时间）
return entry.tokens.expires_at < now_seconds()  // true=过期
```

**`write_all()` 安全写入**：

- 先写临时文件，再 rename（原子写）
- `chmod(path, 0600)` 保护凭据
- **Token 字段脱敏**：在任何日志输出中，`access_token`/`refresh_token` 必须截断为前4字符加 `****`（如 `eyJh****`）；**任何日志输出中不得出现完整 Token**

**验收**：

- `get_for_url()` 在 server_url 变更时返回 `nullopt`；无 serverUrl 字段也返回 `nullopt`
- `is_token_expired()` 三态正确（nullopt/false/true）
- Token 文件权限 0600

### 步骤 2：实现 McpOAuthProvider（oauth_provider.hpp / oauth_provider.cpp）

**PKCE 流程**（对齐 OpenCode `McpOAuthProvider`）：

```cpp
class McpOAuthProvider {
public:
    explicit McpOAuthProvider(const std::string& mcp_name);

    // 生成 code_verifier（32字节随机，base64url 编码）
    static std::string generate_code_verifier();

    // 生成 code_challenge（SHA256(code_verifier)，base64url 编码）
    static std::string generate_code_challenge(const std::string& verifier);

    // 构建 authorization URL（含 PKCE 参数）
    std::string build_auth_url(
        const std::string& auth_endpoint,
        const std::string& client_id,
        const std::string& redirect_uri,
        const std::string& scope,
        const std::string& state,
        const std::string& code_challenge
    );

    // 用 code 交换 token（POST token_endpoint）
    std::future<Tokens> exchange_code(
        const std::string& token_endpoint,
        const std::string& client_id,
        const std::optional<std::string>& client_secret,
        const std::string& code,
        const std::string& code_verifier,
        const std::string& redirect_uri
    );

    // 刷新 token（POST token_endpoint）
    std::future<Tokens> refresh_token(
        const std::string& token_endpoint,
        const std::string& client_id,
        const std::optional<std::string>& client_secret,
        const std::string& refresh_token
    );
};
```

### 步骤 3：OAuth 完整流程集成（manager.cpp 中实现）

**三个方法实现**（对齐 OpenCode `MCP.startAuth` / `MCP.authenticate` / `MCP.finishAuth`）：

#### `start_auth(mcp_name)`（对齐 `MCP.startAuth`）：

1. 确保 OAuth callback 服务器已启动（本地 HTTP 服务器，监听随机端口）
2. 生成 `oauth_state`（32字节随机十六进制），调用 `McpAuth::update_oauth_state()` 存储
3. 构造 `McpOAuthProvider`，发起 `UnauthorizedError` 触发流程
4. 返回 `capturedUrl`（authorization URL）
5. 存储 pending transport（供 `finish_auth` 使用）

#### `authenticate(mcp_name)`（对齐 `MCP.authenticate`，**防竞争条件**）：

1. 调用 `start_auth` 获取 URL
2. **先注册** callback 等待（Promise/channel），**再**尝试打开浏览器（对齐 OpenCode 防竞争条件）
3. 打开浏览器失败时：
   - 发布 EventBus 事件 `"mcp.browser.open.failed"`
   - payload: `{"mcpName": name, "url": auth_url}`
4. 等待 callback 收到 `code`（阻塞，带超时 300s）
5. 校验 `oauth_state`，调用 `McpAuth::clear_oauth_state()`
6. 调用 `finish_auth(mcp_name, code)`

#### `finish_auth(mcp_name, code)`（对齐 `MCP.finishAuth`）：

1. 用 code 交换 token（调用 `McpOAuthProvider::exchange_code()`）
2. 存储 token：`McpAuth::update_tokens(mcp_name, tokens, server_url)`
3. 清除 code_verifier：`McpAuth::clear_code_verifier(mcp_name)`
4. 删除 pending transport
5. 重连 MCP 服务器：`MCPManager::add(mcp_name, config)`

**竞争条件防护原则**（必须严格遵守）：

```
// 正确顺序：
promise = register_callback();  // 先注册
open_browser(url);              // 后开浏览器

// 错误顺序（可能丢失回调）：
open_browser(url);              // 先开浏览器（浏览器极快完成时回调已到达）
promise = register_callback();  // 后注册（丢失）
```

## 验收标准

1. `McpAuth::get_for_url()` 在 server_url 变更时返回 `nullopt`；无 serverUrl 字段也返回 `nullopt`
2. `is_token_expired()` 三态返回正确：nullopt（无token）、false（未过期）、true（已过期）
3. Token 以 0600 权限写入 `~/.turbot/mcp-auth.json`
4. `authenticate()` 先注册 callback 再开浏览器（防竞争条件，代码顺序可审查）
5. 浏览器打开失败时 EventBus 发布 `"mcp.browser.open.failed"` 事件
6. **Token 脱敏**：任何日志输出中不得出现完整 `access_token`/`refresh_token`；所有 Token 必须截断为前 4 字符加 `****`（如 `eyJh****`）
7. 单元测试覆盖率 ≥ 80%

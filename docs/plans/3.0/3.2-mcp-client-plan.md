## 实施步骤

### 步骤 1：实现 MCPClient（client.hpp / client.cpp）

**接口设计**：

```cpp
class MCPClient {
public:
    explicit MCPClient(std::unique_ptr<ITransport> transport);
    ~MCPClient();

    std::future<MCPStatus> connect(
        const std::string& client_name,  // "turbot"
        const std::string& version       // "1.0.0"
    );

    std::future<void> close();

    [[nodiscard]] MCPStatus status() const noexcept;

    std::future<std::vector<MCPTool>>     list_tools();
    std::future<nlohmann::json>           call_tool(
        const std::string& name,
        const nlohmann::json& args,
        int timeout_ms = 30000  // 对齐 DEFAULT_TIMEOUT；resetTimeoutOnProgress = true
    );
    std::future<std::vector<MCPResource>> list_resources();
    std::future<nlohmann::json>           read_resource(const std::string& uri);
    std::future<std::vector<MCPPrompt>>   list_prompts();
    std::future<std::string>              get_prompt(
        const std::string& name,
        const nlohmann::json& args = nlohmann::json::object()
    );

    void on_tools_changed(std::function<void()> callback);
    [[nodiscard]] int pid() const noexcept;
};
```

**MCP initialize 握手**（对齐 OpenCode MCP SDK initialize flow）：

1. 发送 `initialize` 请求：
   ```json
   {
     "method": "initialize",
     "params": {
       "protocolVersion": "2024-11-05",
       "clientInfo": { "name": "turbot", "version": "1.0.0" },
       "capabilities": { "sampling": {} }
     }
   }
   ```
2. 收到响应后发送 `notifications/initialized` 通知
3. 注册 `notifications/tools/list_changed` 通知处理器（触发 `on_tools_changed`）
4. 握手失败时设置 status 为 `Failed`

**call_tool 超时处理**：

- 硬超时 `timeout_ms`（默认 30000ms，对齐 OpenCode DEFAULT_TIMEOUT）
- `resetTimeoutOnProgress = true`：收到 progress 通知时重置超时计时

**验收**：

- `connect()` 完成后 `status() == MCPStatus::Connected`
- `list_tools()` 返回服务器工具列表
- `call_tool()` 超时后返回 error JsonRpcResponse

### 步骤 2：实现 MCPManager 单例（manager.hpp / manager.cpp）

**接口设计**（对齐 OpenCode MCP namespace 所有方法）：

```cpp
class MCPManager {
public:
    static MCPManager& instance();

    void initialize(const std::vector<MCPClientConfig>& configs);

    std::future<MCPStatus> add(const std::string& name, const MCPClientConfig& config);
    std::future<void> connect(const std::string& name);    // MCP.connect()
    std::future<void> disconnect(const std::string& name); // MCP.disconnect()
    void remove(const std::string& name);

    [[nodiscard]] std::unordered_map<std::string, MCPStatus> status() const;

    // 工具命名规则：{sanitized_client}_{sanitized_tool}
    // sanitize = replace(/[^a-zA-Z0-9_-]/g, "_")
    std::future<std::unordered_map<std::string, nlohmann::json>> tools();
    std::future<void> sync_tools_to_registry();

    std::future<std::vector<MCPResource>> all_resources();
    std::future<std::unordered_map<std::string, MCPPrompt>> all_prompts();

    std::future<std::string> start_auth(const std::string& name);
    std::future<MCPStatus>   authenticate(const std::string& name);
    std::future<MCPStatus>   finish_auth(const std::string& name, const std::string& code);
    std::future<void>        remove_auth(const std::string& name);
    bool                     supports_oauth(const std::string& name) const;

    void shutdown();

private:
    static std::vector<int> descendants(int pid);  // pgrep -P 递归获取后代 PID

    mutable std::shared_mutex mutex_;
    std::unordered_map<std::string, std::unique_ptr<MCPClient>> clients_;
    std::unordered_map<std::string, MCPStatus> status_map_;
    std::unordered_map<std::string, MCPClientConfig> configs_;
};
```

**关键实现细节**：

- **孙进程清理**（对齐 OpenCode `descendants(pid)` + SIGTERM 逻辑）：
  - `shutdown()` 时遍历所有 MCPClient，调用 `client->pid()` 获取子进程 PID
  - 调用 `descendants(pid)` 递归获取所有后代 PID
  - 向后代发 SIGTERM，等待 500ms 后强制 SIGKILL

- **`connect(name)`**（对齐 OpenCode `MCP.connect(name)`）：
  - 将配置 `enabled = true`，调用 `add(name, config)` 重连

- **`disconnect(name)`**（对齐 OpenCode `MCP.disconnect(name)`）：
  - 关闭连接，标记配置 `enabled = false`，不删除 configs\_ 条目

- **`sync_tools_to_registry()`**（对齐 OpenCode `convertMcpTool`）：
  - 清除原有 MCP 工具（以 `mcp_` 前缀标记）
  - 对每个 MCPTool：创建 `TurbotTool` 包装，强制 `input_schema.type = "object"`
  - 工具名：`sanitize(server_name) + "_" + sanitize(tool_name)`
  - 注册到 `ToolRegistry::instance()`
  - 发布 EventBus `"mcp.tools.changed"` 事件

**验收**：

- `sync_tools_to_registry()` 后 `ToolRegistry::instance().has("playwright_browser_navigate")` 为 true
- `tools/list_changed` 通知触发重新同步并发布 EventBus 事件
- `shutdown()` 发送 SIGTERM 给所有子进程及其后代

### 步骤 3：MCP → ToolRegistry 适配层

**工具包装类**（内部类，不暴露到 public API）：

```cpp
// manager.cpp 内部实现
class MCPToolWrapper : public turbot::core::tool::Tool {
public:
    MCPToolWrapper(
        const std::string& name,
        const std::string& description,
        const nlohmann::json& schema,
        const std::string& server_name,
        const std::string& original_tool_name
    );

    std::string execute(const nlohmann::json& args) override;

private:
    std::string server_name_;
    std::string original_tool_name_;
};
```

**Schema 适配规则**（对齐 OpenCode `convertMcpTool`）：

- 强制 `schema["type"] = "object"`
- 强制 `schema["additionalProperties"] = false`
- 若 `schema` 为 null/empty，使用 `{"type": "object", "properties": {}}`

**验收**：

- MCP 工具调用正确透传到 `MCPClient::call_tool()`
- 工具执行超时遵循 `MCPClientConfig::timeout_ms`

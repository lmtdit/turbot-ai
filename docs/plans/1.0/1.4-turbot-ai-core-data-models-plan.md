## 1. 概述

本计划是 Turbot-AI 项目的第四阶段实现，旨在建立核心数据模型。核心数据模型包括 Message 和 Part 系统，是整个项目的的数据基础，用于表示 AI 对话中的消息和消息的各个组成部分。

### 1.1 目标

- ✅ 实现 Message 数据模型
- ✅ 实现 12 种 Part 类型
- ✅ 实现消息持久化
- ✅ 实现 Token 统计
- ✅ 实现消息查询和检索

### 1.2 依赖关系

- **前置依赖**: 1.1 - 基础架构计划, 1.2 - 存储层计划
- **后置依赖**: Provider 系统、会话系统、Agent 系统

### 1.3 交付物

- ✅ Message 数据模型 (`libs/core/include/turbot/core/message/message.hpp`)

Part Part::create_tool(
    const std::string& tool_id,
    const std::string& tool_name,
    const nlohmann::json& arguments,
    const std::optional<nlohmann::json>& result
) {
    Part part;
    part.id = generate_uuid();
    part.type = PartType::Tool;
    part.data = {
        {"tool_id", tool_id},
        {"tool_name", tool_name},
        {"arguments", arguments}
    };
    if (result) part.data["result"] = *result;
    part.time_created = part.time_updated = current_timestamp_ms();
    return part;
}

### 4.2 Message 实现

```cpp
Message::Message(const std::string& session_id, Role role,
                 const std::string& agent,
                 const std::string& model_id,
                 const std::string& provider_id) {
    generate_id();
    info_.session_id = session_id;
    info_.role = role;
    info_.agent = agent;
    info_.model_id = model_id;
    info_.provider_id = provider_id;
    update_timestamp();
}

void Message::save() {
    if (!db_) return;
    MessageDao dao(db_);
    dao.create_message(info_);
    for (const auto& part : parts_) {
        Part p = part;
        p.message_id = info_.id;
        p.session_id = info_.session_id;
        dao.create_part(p);
    }
}

std::string Message::get_text() const {
    std::string text;
    for (const auto& part : parts_) {
        if (part.is_text()) {
            text += part.get_text();
        }
    }
    return text;
}
```

## 7. 使用示例

````cpp
#include <turbot/core/message/message.hpp>
#include <turbot/storage/sqlite_database.hpp>

using namespace turbot::core;
using namespace turbot::storage;
using namespace turbot::storage::sqlite;

// 创建数据库
auto db = std::make_shared<SQLiteDatabase>(DatabaseConfig{.path = ":memory:"});

// 创建用户消息
Message user_msg("session123", Role::User, "build", "gpt-4", "openai");
user_msg.add_text("Write a function to add two numbers");
user_msg.set_database(db);
user_msg.save();

// 创建助手消息
Message assistant_msg("session123", Role::Assistant, "build", "gpt-4", "openai");
assistant_msg.add_reasoning("I need to create a simple addition function in C++");
assistant_msg.add_text("```cpp\nint add(int a, int b) { return a + b; }\n```");
assistant_msg.set_database(db);
assistant_msg.save();

// 查询会话的所有消息
auto messages = Message::list_by_session("session123", db);
for (const auto& msg : messages) {
    TURBOT_LOG_INFO("Message from {}: {}",
        role_to_string(msg.role()),
        msg.get_text());
}

// Token 统计
TokenUsage usage;
usage.input = 100;
usage.output = 50;

nlohmann::json pricing = {
    {"input", 0.01},
    {"output", 0.03}
};

assistant_msg.update_tokens(usage, pricing);
TURBOT_LOG_INFO("Cost: ${}", assistant_msg.cost());
````

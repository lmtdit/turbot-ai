## 决策流程

1. **提议**: 创建 ADR 草案，状态为"提议中"
2. **讨论**: 架构团队评审，收集反馈
3. **批准**: 达成共识后，状态变更为"已批准"
4. **实施**: 按决策执行开发
5. **归档**: 决策实施完成后归档

## 状态说明

| 状态      | 说明                  |
| --------- | --------------------- |
| 📋 提议中 | 决策草案，等待评审    |
| ✅ 已批准 | 决策已批准，可实施    |
| 🔄 已变更 | 决策已被后续 ADR 修改 |
| ❌ 已废弃 | 决策已不再适用        |

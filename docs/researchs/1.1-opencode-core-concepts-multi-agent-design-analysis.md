# OpenCode 核心概念与多代理协作架构深度分析

## 1. 执行摘要

本文档基于对 OpenCode 源码的深入探索，重点分析了 session/**、agent/**、acp/** 三个核心模块的实现细节，揭示了 OpenCode 的核心设计理念、多代理协作机制、会话管理流程以及 ACP 协议集成方案。本文档为理解 OpenCode 的技术架构和设计决策提供全面的技术参考。

**关键发现**：
- OpenCode 采用事件驱动的异步架构，通过 Bus 事件总线实现模块解耦
- 多代理协作通过 task 工具和独立的子会话实现，支持嵌套调用
- 会话管理采用智能压缩机制，自动处理上下文溢出
- ACP 协议实现提供了标准化的 IDE 集成方案

## 2. 核心概念

### 2.1 Session（会话）- 核心抽象

#### 2.1.1 会话生命周期

会话是 OpenCode 的核心抽象，代表一次完整的 AI 交互对话。会话具有以下生命周期：

```
创建 → 激活 → 运行 → 压缩 → 归档
```

**创建阶段**：
- 通过 `Session.create()` 创建新会话
- 支持通过 `Session.fork()` 从现有会话 fork
- 关联到项目和工作空间
- 应用默认权限规则

**激活阶段**：
- 用户输入触发 `SessionPrompt.prompt()`
- 进入 `SessionPrompt.loop()` 主循环
- 状态标记为 `busy`

**运行阶段**：
- 执行 LLM 调用和工具操作
- 实时更新消息和部分（Part）
- 监控 token 使用和成本

**压缩阶段**：
- 检测上下文溢出
- 触发 `SessionCompaction.process()`
- 生成对话摘要
- 清理旧消息

**归档阶段**：
- 通过 `Session.setArchived()` 标记
- 从会话列表中隐藏

#### 2.1.2 会话数据模型


#### 2.1.3 关键设计特性

**父子关系与 Fork 机制**：

```

    ↓

    ↓
Session C (孙会话) - 可以继续 Fork
```

Fork 机制允许：
- 从任意消息点创建新分支
- 保留到 Fork 点的所有消息历史
- 独立运行，不影响原会话
- 支持 A/B 测试和并行开发

**摘要统计系统**：

```typescript
})
```

自动跟踪：
- 代码添加/删除行数
- 修改的文件数量
- 具体的 diff 信息

**回滚系统**：

#### 2.2.2 Part 类型系统

OpenCode 定义了 12 种 Part 类型，每种类型都有特定的用途：

| Part 类型 | 用途 | 关键字段 |
|----------|------|----------|
| `TextPart` | 文本内容 | text, synthetic, ignored, time |
| `ToolPart` | 工具调用 | tool, callID, state, metadata |
| `ReasoningPart` | 推理过程 | text, metadata, time |
| `FilePart` | 文件附件 | mime, filename, url, source |
| `SubtaskPart` | 子任务标记 | prompt, description, agent, command |
| `StepStartPart` | 步骤开始标记 | snapshot |
| `StepFinishPart` | 步骤完成标记 | reason, snapshot, tokens, cost |
| `SnapshotPart` | 文件系统快照 | snapshot |
| `PatchPart` | 代码补丁 | hash, files |
| `AgentPart` | 代理提及 | name, source |
| `RetryPart` | 重试记录 | attempt, error, time |
| `CompactionPart` | 压缩标记 | auto, overflow |

**ToolPart 状态机**：

#### 2.2.3 消息流式处理

```typescript
export const stream = fn(Identifier.schema("session"), async function* (sessionID)) {
  const size = 50
  let offset = 0
  
  while (true) {
    // 分页查询消息
    const rows = Database.use((db) =>
      db.select()
        .from(MessageTable)
        .where(eq(MessageTable.session_id, sessionID))
        .orderBy(desc(MessageTable.time_created))
        .limit(size)
        .offset(offset)
        .all()
    )
    
    if (rows.length === 0) break
    
    // 批量查询消息部分
    const ids = rows.map((row) => row.id)
    const partsByMessage = new Map<string, MessageV2.Part[]>()
    
    if (ids.length > 0) {
      const partRows = Database.use((db) =>
        db.select()
          .from(PartTable)
          .where(inArray(PartTable.message_id, ids))
          .orderBy(PartTable.message_id, PartTable.id)
          .all()
      )
      
      for (const row of partRows) {
        const part = {
          ...row.data,
          id: row.id,
          sessionID: row.session_id,
          messageID: row.message_id,
        } as MessageV2.Part
        const list = partsByMessage.get(row.message_id)
        if (list) list.push(part)
        else partsByMessage.set(row.message_id, [part])
      }
    }
    
    // 产出消息
    for (const row of rows) {
      const info = { 
        ...row.data, 
        id: row.id, 
        sessionID: row.session_id 
      } as MessageV2.Info
      yield {
        info,
        parts: partsByMessage.get(row.id) ?? [],
      }
    }
    
    offset += rows.length
    if (rows.length < size) break
  }
}
```

**特性**：
- 分页加载，避免内存溢出
- 异步生成器，按需加载
- 保持时间顺序（最新的在前）
- 批量查询 Part，减少数据库往返

### 2.5 Permission（权限）- 安全控制核心

#### 2.5.1 权限规则集

```typescript
PermissionNext.Ruleset = Rule[]

Rule {
  permission: string          // 权限类型（edit, read, bash 等）
  pattern: string             // 匹配模式（支持通配符）
  action: "allow" | "deny" | "ask"
}
```

#### 2.5.2 权限评估流程

```typescript
function evaluate(permission: string, pattern: string, ...rulesets: Ruleset[]): Rule {
  const merged = merge(...rulesets)
  
  // 找到最后匹配的规则（最后匹配原则）
  const match = merged.findLast(
    (rule) => 
      Wildcard.match(permission, rule.permission) && 
      Wildcard.match(pattern, rule.pattern)
    )
  )
  
  // 默认询问
  return match ?? { action: "ask", permission, pattern: "*" }
}
```

**匹配逻辑**：
1. 合并所有规则集
2. 使用通配符匹配
3. 最后匹配的规则生效
4. 未匹配则默认为 `ask`

#### 2.5.3 权限请求处理

```typescript
export const ask = fn(
  Request.partial({ id: true }).extend({
    ruleset: Ruleset,
  }),
  async (input) => {
    const s = await state()
    const { ruleset, ...request } = input
    
    for (const pattern of request.patterns ?? []) {
      const rule = evaluate(request.permission, pattern, ruleset, s.approved)
      
      if (rule.action === "deny")
        throw new DeniedError(ruleset.filter(
          (r) => Wildcard.match(request.permission, r.permission)
        ))
      
      if (rule.action === "ask") {
        const id = input.id ?? Identifier.ascending("permission")
        return new Promise<void>((resolve, reject) => {
          const info: Request = { id, ...request }
          s.pending[id] = { info, resolve, reject }
          Bus.publish(Event.Asked, info)
        })
      }
      
      if (rule.action === "allow") continue
    }
  },
)
```

#### 2.5.4 权限响应处理

```typescript
export const reply = fn(
  z.object({
    requestID: Identifier.schema("permission"),
    reply: Reply,  // "once" | "always" | "reject"
    message: z.string().optional(),
  }),
  async (input) => {
    const s = await state()
    const existing = s.pending[input.requestID]
    if (!existing) return
    
    delete s.pending[input.requestID]
    Bus.publish(Event.Replied, {
      sessionID: existing.info.sessionID,
      requestID: input.requestID,
      reply: input.reply,
    })
    
    if (input.reply === "reject") {
      existing.reject(input.message ? 
        new CorrectedError(input.message) : 
        new RejectedError()
      )
      
      // 拒绝会话中其他待处理的权限请求
      const sessionID = existing.info.sessionID
      for (const [id, pending] of Object.entries(s.pending)) {
        if (pending.info.sessionID === sessionID) {
          delete s.pending[id]
          Bus.publish(Event.Replied, {
            sessionID: pending.info.sessionID,
            requestID: pending.info.id,
            reply: "reject",
          })
          pending.reject(new RejectedError())
        }
      }
      return
    }
    
    if (input.reply === "once") {
      existing.resolve()
      return
    }
    
    if (input.reply === "always") {
      // 保存到已批准列表
      for (const pattern of existing.info.always) {
        s.approved.push({
          permission: existing.info.permission,
          pattern,
          action: "allow",
        })
      }
      
      existing.resolve()
      
      // 处理同一会话中的其他权限请求
      const sessionID = existing.info.sessionID
      for (const [id, pending] of Object.entries(s.pending)) {
        if (pending.info.sessionID !== sessionID) continue
        
        const ok = pending.info.patterns.every(
          (pattern) => evaluate(
            pending.info.permission, 
            pattern, 
            s.approved
          ).action === "allow"
        )
        
        if (!ok) continue
        
        delete s.pending[id]
        Bus.publish(Event.Replied, {
          sessionID: pending.info.sessionID,
          requestID: pending.info.id,
          reply: "always",
        })
        pending.resolve()
      }
    }
  },
)
```

## 3. 核心流程

### 3.1 SessionPrompt.loop 主循环

#### 3.1.1 循环架构

```
┌───────────────────────────────────────────────────────────────┐
│                   SessionPrompt.loop()                       │
├───────────────────────────────────────────────────────────────┤
│                                                              │
│  while (true) {                                                │
│    1. 获取消息流（过滤已压缩的）                            │
│    2. 找到最后一条用户消息和助手消息                        │
│    3. 收集待处理任务（subtask/compaction）                   │
│    4. 检查退出条件                                        │
│    5. 处理路径选择：                                       │
│       路径1: 待处理的子任务 (SubtaskPart)                  │
│       路径2: 待处理的压缩 (CompactionPart)                │
│       路径3: 检查是否需要压缩                              │
│       路径4: 正常 LLM 处理                                 │
│  }                                                            │
│                                                              │
└───────────────────────────────────────────────────────────────┘
```

#### 3.1.2 完整实现代码

**位置**：`/Users/jg/Codes/turbot/opencode/packages/opencode/src/session/prompt.ts:140-580`

```typescript
export const loop = fn(LoopInput, async (input) => {
  const { sessionID, resume_existing } = input
  
  // 启动或恢复会话状态
  const abort = resume_existing ? resume(sessionID) : start(sessionID)
  
  // 结构化输出状态
  let structuredOutput: unknown | undefined
  
  let step = 0
  const session = await Session.get(sessionID)
  
  while (true) {
    SessionStatus.set(sessionID, { type: "busy" })
    
    // 获取消息流（过滤已压缩的）
    let msgs = await MessageV2.filterCompacted(MessageV2.stream(sessionID))
    
    // 找到最后一条用户消息和助手消息
    let lastUser: MessageV2.User | undefined
    let lastAssistant: MessageV2.Assistant | undefined
    let tasks: (MessageV2.CompactionPart | MessageV2.SubtaskPart)[] = []
    
    // 消息遍历
    for (let i = msgs.length - 1; i >= 0; i--) {
      const msg = msgs[i]
      if (msg.info.role === "user") lastUser = msg.info as MessageV2.User
      if (!lastAssistant && msg.info.role === "assistant") 
        lastAssistant = msg.info as MessageV2.Assistant
      if (lastUser && lastAssistant) break
      
      // 收集待处理任务
      if (lastUser && !lastFinished) {
        const task = msg.parts.filter((part) => 
          part.type === "compaction" || part.type === "subtask"
        )
        if (task) tasks.push(...task)
      }
    }
    
    // 退出条件检查
    if (!lastUser) throw new Error("No user message found")
    
    if (lastAssistant?.finish && 
        !["tool-cacks", "unknown"].includes(lastAssistant.finish) &&
        lastUser.id < lastAssistant.id) {
      break  // 退出循环
    }
    
    step++
    
    // 确保标题
    if (step === 1)
      ensureTitle({
        session,
        modelID: lastUser.model.modelID,
        providerID: lastUser.model.providerID,
        history: msgs,
      })
    
    // 处理路径选择
    const task = tasks.pop()
    
    // 路径1: 处理待处理的子任务
    if (task?.type === "subtask") {
      const taskTool = await TaskTool.init()
      const taskModel = task.model ? 
        await Provider.getModel(task.model.providerID, task.model.modelID) : model
      
      const assistantMessage = await Session.updateMessage({
        id: Identifier.ascending("message"),
        role: "assistant",
        parentID: lastUser.id,
        sessionID,
        mode: task.agent,
        agent: task.agent,
        variant: lastUser.variant,
        path: {
          cwd: Instance.directory,
          root: Instance.worktree,
        },
        cost: 0,
        tokens: {
          input: 0,
          output: 0,
          reasoning: 0,
          cache: { read: 0, write: 0 },
        },
        modelID: taskModel.id,
        providerID: taskModel.providerID,
        time: { created: Date.now() },
      }) as MessageV2.Assistant
      
      let part = await Session.updatePart({
        id: Identifier.ascending("part"),
        messageID: assistantMessage.id,
        sessionID: assistantMessage.sessionID,
        type: "tool",
        callID: ulid(),
        tool: TaskTool.id,
        state: {
          status: "running",
          input: {
            prompt: task.prompt,
            description: task.description,
            subagent_type: task.agent,
            command: task.command,
          },
          time: { start: Date.now() },
        },
      })
      
      const taskArgs = {
        prompt: task.prompt,
        description: task.description,
        subagent_type: task.agent,
        command: task.command,
      }
      
      // 执行子任务
      const taskAgent = await Agent.get(task.agent)
      const taskCtx: Tool.Context = {
        agent: task.agent,
        messageID: assistantMessage.id,
        sessionID: sessionID,
        abort,
        callID: part.callID,
        extra: { bypassAgentCheck: true },
        messages: msgs,
        async metadata(input) {
          await Session.updatePart({
            ...part,
            type: "tool",
            state: {
              ...part.state,
              ...input,
            },
          })
        },
        async ask(req) {
          await PermissionNext.ask({
            ...req,
            sessionID: sessionID,
            ruleset: PermissionNext.merge(taskAgent.permission, session.permission ?? []),
          })
        },
      }
      
      const result = await taskTool.execute(taskArgs, taskCtx)
      
      assistantMessage.finish = "tool-calls"
      assistantMessage.time.completed = Date.now()
      await Session.updateMessage(assistantMessage)
      
      if (result && part.state.status === "running") {
        await Session.updatePart({
          ...part,
          state: {
            status: "completed",
            input: part.state.input,
            title: result.title,
            metadata: result.metadata,
            output: result.output,
            attachments,
            time: { ...part.state.time, end: Date.now() },
          },
        })
      }
      
      if (!result) {
        await Session.updatePart({
          ...part,
          state: {
            status: "error",
            error: executionError ? 
              `Tool execution failed: ${executionError.message}` : 
              "Tool execution failed",
            time: {
              start: Date.now(),
              end: Date.now(),
            },
          },
        })
      }
      
      // 如果是命令模式，添加合成用户消息
      if (task.command) {
        const summaryUserMsg: MessageV2.User = {
          id: Identifier.ascending("message"),
          sessionID,
          role: "user",
          time: { created: Date.now() },
          agent: lastUser.agent,
          model: lastUser.model,
        }
        await Session.updateMessage(summaryUserMsg)
        await Session.updatePart({
          id: Identifier.ascending("part"),
          messageID: summaryUserMsg.id,
          sessionID,
          type: "text",
          text: "Summarize the task tool output above and continue with your task.",
          synthetic: true,
        })
      }
      
      continue
    }
    
    // 路径2: 处理待处理的压缩
    if (task?.type === "compaction") {
      const result = await SessionCompaction.process({
        messages: msgs,
        parentID: lastUser.id,
        abort,
        sessionID,
        auto: task.auto,
        overflow: task.overflow,
      })
      if (result === "stop") break
      continue
    }
    
    // 路径3: 检查是否需要压缩
    if (
      lastFinished &&
      lastFinished.summary !== true &&
      (await SessionCompaction.isOverflow({ 
        tokens: lastFinished.tokens, 
        model 
      }))
    ) {
      await SessionCompaction.create({
        sessionID,
        agent: lastUser.agent,
        model: lastUser.model,
        auto: true,
      })
      continue
    }
    
    // 路径4: 正常处理 - 调用 LLM
    const agent = await Agent.get(lastUser.agent)
    const maxSteps = agent.steps ?? Infinity
    const isLastStep = step >= maxSteps
    
    msgs = await insertReminders({
      messages: msgs,
      agent,
      session,
    })
    
    const processor = SessionProcessor.create({
      assistantMessage: await Session.updateMessage({
        id: Identifier.ascending("message"),
        parentID: lastUser.id,
        role: "assistant",
        mode: agent.name,
        agent: agent.name,
        variant: lastUser.variant,
        path: {
          cwd: Instance.directory,
          root: Instance.worktree,
        },
        cost: 0,
        tokens: {
          input: 0,
          output: 0,
        },
        modelID: model.id,
        providerID: model.providerID,
        time: { created: Date.now() },
        sessionID,
      }) as MessageV2.Assistant,
      sessionID: sessionID,
      model,
      abort,
    })
    
    const tools = await resolveTools({
      agent,
      session,
      model,
      tools: lastUser.tools,
      processor,
      bypassAgentCheck,
      messages: msgs,
    })
    
    // 构建系统提示词
    const system = [
      ...(await SystemPrompt.environment(model)),
      ...(await InstructionPrompt.system())
    ]
    
    const result = await processor.process({
      user: lastUser,
      agent,
      abort,
      sessionID,
      system,
      messages: [
        ...MessageV2.toModelMessages(msgs, model),
        ...(isLastStep ? [
          {
            role: "assistant",
            content: MAX_STEPS,
          },
        ] : []),
      ],
      tools,
      model,
    })
    
    // 处理结构化输出
    if (structuredOutput !== undefined) {
      processor.message.structured = structuredOutput
      processor.message.finish = processor.message.finish ?? "stop"
      await Session.updateMessage(processor.message)
      break
    }
    
    // 检查是否完成
    const modelFinished = processor.message.finish && 
      !["tool-calls", "unknown"].includes(processor.message.finish)
    
    if (modelFinished && !processor.message.error) {
      if (format.type === "json_schema") {
        processor.message.error = new MessageV2.StructuredOutputError({
          message: "Model did not produce structured output",
          retries: 0,
        }).toObject()
        await Session.updateMessage(processor.message)
        break
      }
    }
    
    if (result === "stop") break
    if (result === "compact") {
      await SessionCompaction.create({
        sessionID,
        agent: lastUser.agent,
        model: lastUser.model,
        auto: true,
        overflow: !processor.message.finish,
      })
    }
    continue
  }
  
  // 清理和返回
  SessionCompaction.prune({ sessionID })
  for await (const item of MessageV2.stream(sessionID)) {
    if (item.info.role === "user") continue
    return item
  }
  throw new Error("Impossible")
})
```

#### 3.1.3 关键设计特点

**1. 三阶段处理**：
- 阶段 1：检查待处理任务（subtask/compaction）
- 阶段 2：检查是否需要压缩
- 阶段 3：正常 LLM 处理

**2. 退出条件**：
- 助手消息完成且用户消息早于助手消息
- 发生错误或被拒绝
- 达到最大步骤数

**3. 状态管理**：
- 使用 `step` 计数器跟踪循环迭代
- 通过 `SessionStatus` 维护会话状态
- 支持 `abort` 取消操作

**4. 增量式优化**：
- 插入提醒消息保持焦点
- 自动压缩避免上下文溢出
- Prune 机制清理旧数据

```typescript
export async function isOverflow(input: { 
  tokens: MessageV2.Assistant["tokens"]; 
  model: Provider.Model 
}) {
  const config = await Config.get()
  if (config.compaction?.auto === false) return false
  
  const context = input.model.limit.context
  if (context === 0) return false
  
  const count = input.tokens.total || 
    input.tokens.input + input.tokens.output + 
    input.tokens.cache.read + input.tokens.cache.write
  
  const reserved = config.compaction?.reserved ?? 
    Math.min(COMPACTION_BUFFER, ProviderTransform.maxOutputTokens(input.model))
  
  const usable = input.model.limit.input 
    ? input.model.limit.input - reserved
    : context - ProviderTransform.maxOutputTokens(input.model)
  
  return count >= usable  // 超过可用上下文时触发
}
```

**参数说明**：
- `COMPACTION_BUFFER`: 默认 20,000 tokens
- `reserved`: 预留空间，确保模型可以完成当前响应
- `usable`: 实际可用上下文大小

```typescript
  parentID: string
  messages: MessageV2.WithParts[]
  sessionID: string
  abort: AbortSignal
  auto: boolean
  overflow?: boolean
}) {
  const userMessage = input.messages.findLast(
    (m) => m.info.id === input.parentID
  )!.info as MessageV2.User
  
  let messages = input.messages
  let replay: MessageV2.WithParts | undefined
  
  // 处理溢出场景
  if (input.overflow) {
    const idx = input.messages.findIndex((m) => m.info.id === input.parentID)
    // 向前查找可以压缩的点
    for (let i = idx - 1; i >= 0; i--) {
      const msg = input.messages[i]
      if (msg.info.role === "user" && 
          !msg.parts.some((p) => p.type === "compaction")) {
        replay = msg
        messages = input.messages.slice(0, i)
        break
      }
    }
  }
  
  // 使用 compaction agent
  const agent = await Agent.get("compaction")
  const processor = SessionProcessor.create({...})
  
  // 压缩提示词
  const defaultPrompt = `Provide a detailed prompt for continuing our conversation above.
Focus on information that would be helpful for continuing the conversation...`
  
  // 处理压缩
  const result = await processor.process({
    user: userMessage,
    agent,
    abort: input.abort,
    sessionID: input.sessionID,
    tools: {},  // 压缩时不使用工具
    system: [],
    messages: [
      ...MessageV2.toModelMessages(messages, model, { stripMedia: true }),
      {
        role: "user",
        content: [{ type: "text", text: promptText }],
      },
    ],
    model,
  })
  
  // 如果需要回放，重新创建消息
  if (result === "continue" && input.auto && replay) {
    const original = replay.info as MessageV2.User
    const replayMsg = await Session.updateMessage({
      id: Identifier.ascending("message"),
      role: "user",
      sessionID: input.sessionID,
      time: { created: Date.now() },
      agent: original.agent,
      model: original.model,
    })
    
    // 复制消息部分（跳过 compaction 部分）
    for (const part of replay.parts) {
      if (part.type === "compaction") continue
      const replayPart = part.type === "file" && MessageV2.isMedia(part.mime)
        ? { type: "text", text: `[Attached ${part.mime}: ${part.filename}]` }
        : part
      await Session.updatePart({
        ...replayPart,
        id: Identifier.ascending("part"),
        messageID: replayMsg.id,
        sessionID: input.sessionID,
      })
    }
  }
  
  Bus.publish(Event.Compacted, { sessionID: input.sessionID })
  return "continue"
```

```typescript
export async function prune(input: { sessionID: string }) {
  const msgs = await Session.messages({ sessionID: input.sessionID })
  let total = 0
  let pruned = 0
  const toPrune = []
  let turns = 0
  
  // 向后遍历消息
  for (let msgIndex = msgs.length - 1; msgIndex >= 0; msgIndex--) {
    const msg = msgs[msgIndex]
    if (msg.info.role === "user") turns++
    if (turns < 2) continue  // 保留最近2轮
    if (msg.info.role === "assistant" && msg.info.summary) break
    
    // 查找可清理的工具调用
    for (const part of msg.parts) {
      if (part.type === "tool" && part.state.status === "completed") {
        if (PRUNE_PROTECTED_TOOLS.includes(part.tool)) continue  // 保护特定工具
        
        if (part.state.time.compacted) break
        
        const estimate = Token.estimate(part.state.output)
        total += estimate
        
        // 超过保护阈值后开始清理
        if (total > PRUNE_PROTECT) {
          pruned += estimate
          toPrune.push(part)
        }
      }
    }
  }

  }
}
```

### 3.5 权限评估流程

#### 3.5.1 规则匹配算法

```typescript
function evaluate(permission: string, pattern: string, ...rulesets: Ruleset[]): Rule {
  const merged = merge(...rulesets)
  
  // 找到最后匹配的规则
  const match = merged.findLast(
    (rule) => 
      Wildcard.match(permission, rule.permission) && 
      Wildcard.match(pattern, rule.pattern)
    )
  )
  
  // 默认询问
  return match ?? { action: "ask", permission, pattern: "*" }
}
```

**通配符匹配逻辑**：
- 支持通配符 `*`
- 支持模式匹配（如 `*.env`）
- 顺序：权限名称匹配 → 模式匹配

#### 3.5.2 权限请求队列

```typescript
export const ask = fn(
  Request.partial({ id: true }).extend({
    ruleset: Ruleset,
  }),
  async (input) => {
    const s = await state()
    const { ruleset, ...request } = input
    
    for (const pattern of request.patterns ?? []) {
      const rule = evaluate(request.permission, pattern, ruleset, s.approved)
      
      if (rule.action === "deny")
        throw new DeniedError(ruleset.filter(
          (r) => Wildcard.match(request.permission, r.permission)
        ))
      
      if (rule.action === "ask") {
        const id = input.id ?? Identifier.ascending("permission")
        return new Promise<void>((resolve, reject) => {
          const info: Request = { id, ...request }
          s.pending[id] = { info, resolve, reject }
          Bus.publish(Event.Asked, info)
        })
      }
      
      if (rule.action === "allow") continue
    }
  },
)
```

**队列机制**：
- 使用 Promise 链确保顺序处理
- 支持批量批准（`always`）
- 自动拒绝其他请求（`reject`）

```typescript
export namespace Bus {
  const eventAbort = new AbortController()
  
  export function publish<T>(event: BusEvent<T>) {
    const subscribers = event.subscribers
    if (!subscribers.size) return
    
    const data = JSON.stringify(event.schema.parse(data))
    
    for (const subscriber of subscribers) {
      subscriber(data).catch((error) => {
        log.error("subscriber error", {
          error,
          subscriber: subscriber.name,
        })
      })
    }
  }
  
  export function subscribe<T>(
    event: BusEvent<T>,
    callback: (data: T) => Promise<void>
  ): () => void {
    const subscribers = event.subscribers
    subscribers.add(callback)
    
    return () => {
      subscribers.delete(callback)
    }
  }
}
```

```typescript
async prompt(params: PromptRequest) {
  const sessionID = params.sessionId
  const session = this.sessionManager.get(sessionID)
  const directory = session.cwd
  const current = session.model
  const model = current ?? (await defaultModel(this.config, directory))
  const agent = session.modeId ?? (await AgentModule.defaultAgent())

  // 转换 ACP 内容块到 OpenCode 格式
  const parts: Array<
    | { type: "text"; text: string; synthetic?: boolean; ignored?: boolean }
    | { type: "file"; url: string; filename: string; mime: string }
  > = []
  
  for (const part of params.prompt) {
    switch (part.type) {
      case "text":
        const audience = part.annotations?.audience
        const forAssistant = audience?.length === 1 && audience[0] === "assistant"
        const forUser = audience?.length === 1 && audience[0] === "user"
        parts.push({
          type: "text",
          text: part.text,
          ...(forAssistant && { synthetic: true }),
          ...(forUser && { ignored: true }),
        })
        break
      case "image":
        if (part.data) {
          parts.push({
            type: "file",
            url: `data:${part.mimeType};base64,${part.data}`,
            filename: "image",
            mime: part.mimeType,
          })
        }
        break
      // ... 其他类型处理
    }
  }

  // 检测命令
  const cmd = (() => {
    const text = parts.filter((p): p is { type: "text"; text: string } => p.type === "text")
      .map((p) => p.text).join("").trim()
    if (!text.startsWith("/")) return
    const [name, ...rest] = text.slice(1).split(/\s+/)
    return { name, args: rest.join(" ").trim() }
  })()

  // 执行 prompt 或命令
  if (!cmd) {
    const response = await this.sdk.session.prompt({
      sessionID,
      model: { providerID: model.providerID, modelID: model.modelID },
      variant: this.sessionManager.getVariant(sessionID),
      parts,
      agent,
      directory,
    })
    const msg = response.data?.info
    await sendUsageUpdate(this.connection, this.sdk, sessionID, directory)
    return {
      stopReason: "end_turn",
      usage: msg ? buildUsage(msg) : undefined,
      _meta: {},
    }
  }

  // 处理内置命令
  if (cmd.name === "compact") {
    await this.sdk.session.summarize({ 
      sessionID, 
      directory, 
      providerID: model.providerID, 
      modelID: model.modelID 
    })
  }

  return { stopReason: "end_turn", _meta: {} }
}
```
